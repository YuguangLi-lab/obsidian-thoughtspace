## 安装

先关闭 Obsidian，解压后进入本目录。请把下面的路径替换为自己的笔记库：

```sh
python3 scripts/install.py "/你的笔记库路径" --dry-run
python3 scripts/install_thoughtspace_folio_9.py "/你的笔记库路径" --dry-run
```

确认检查通过后，去掉 `--dry-run` 分别安装主题和配套插件，再打开 Obsidian。安装器会备份旧文件。插件安装器仅接受校验一致的 Folio 定制版 1–8 或相同的第 9 版；遇到其他版本或自定义修改会停止，不覆盖它们。不要用本包降级官方 ThoughtSpace 1.3.36。

`SHA256SUMS.json` 列出包内文件校验值。`integration-source/` 仅包含本次修复的局部源码与回归测试，不是可独立构建的完整插件仓库。
