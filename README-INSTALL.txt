ThoughtSpace Whiteboard — Install or update / 安装或更新

Extract this ZIP. Copy only main.js, manifest.json and styles.css from its
thoughtspace folder directly into your vault's .obsidian/plugins/thoughtspace/
folder (or the equivalent folder under your custom configuration directory).
Keep all three files from the same package. Do not add another nested folder.
When updating, preserve data.json, collection-drafts/ and all other existing
plugin data, then reload the plugin in Obsidian.

解压后，将 thoughtspace 文件夹中的 main.js、manifest.json 和 styles.css
三个文件直接复制到笔记库的 .obsidian/plugins/thoughtspace/ 中；使用自定义
配置目录时改为对应目录。三个文件须来自同一安装包，不要再嵌套一层文件夹。
更新时只替换这三个文件，保留 data.json、collection-drafts/ 和其他已有插件
数据，然后在 Obsidian 中重新加载插件。

The included LICENSE and THIRD_PARTY_NOTICES.md contain the license notices.
SHA256SUMS.txt supplied alongside the package can be used to check the ZIP and
the three standalone runtime downloads. It is not a plugin installation file.
LICENSE 与 THIRD_PARTY_NOTICES.md 为许可说明；包外提供的 SHA256SUMS.txt
用于人工核验 ZIP 及三个独立运行文件，不需要复制为插件运行文件。
