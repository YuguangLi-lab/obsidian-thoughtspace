# 1.0.19 — 移动、分组大纲、长文处理与预览资源优化

本轮以完整备份的 **1.0.18** 为基线；包含前轮未提交的本地改动，未将 Git HEAD 当作当前版本。

**2,549 / 2,549** 全仓测试通过，新增 **31 项**。TypeScript、生产构建、发布元数据以及 **7 / 7** 发布脚本测试通过。ESLint **0 错误、79 项既有警告**。

## 改动内容

- 普通卡片移动和键盘微调：通过当前锁定、隐藏和分组约束检查后，直接使用按白板顺序得到的对象，省去展开索引和最终整板扫描。空选择直接返回。
- 布局成员查询：仅遇到分组或折叠根节点时才建立一次展开索引，普通独立卡片不扫描无关节点。
- 批量拖动提交：直接比较几何和自动尺寸标记，只有真正改变时才分配修改对象，空草稿不扫描整板。并发移动、尺寸变化、锁定、删除仍使整批操作取消。
- 分组大纲：分散分组按附近成员建立归属，保持最小框优先及确定性顺序；密集重叠、深层嵌套沿用原查找路径，避免大嵌套退化。
- 对齐辅助线：按原顺序比较三个候选点及相邻锚点，减少每帧小数组。保留距离阈值、等距选择和轴锁语义。
- Markdown 注释遮罩：按实际注释片段拼接等长空白，不再把整行拆成字符数组；代码、转义、跨行注释和 UTF-16 原文位置保持一致。
- 写作字数：混合中日韩文本逐段统计，减少扩张文本和词数组。初版曾使纯英文计数变慢，最终保留其原生匹配路径。
- 摘录搜索：每次操作只解析一次查询；当前项仍匹配时停止后续扫描，否则保留首个匹配项回退规则。
- SVG 连线：几何变化时复用已有箭头标记，只有新行或颜色样式变化才查询标记集合。

## 修复的两个问题

1. **取消后的预览资源清理不完整。** 卡片与文本原生 Markdown 预览取消、替换或超时后，迟到的处理器仍可能注册回调或子组件。新增插件自身的一次性 Component，在作用域关闭后立即释放迟到登记，不重载旧作用域，也不修改 Obsidian 全局原型。六项生产预览生命周期回归在旧版失败、修复后通过。
2. **长连线标签可能截断 emoji。** 原截断位置可能落在 UTF-16 代理对中间，新版保留完整代理对；悬停提示仍显示完整原文。

- **17 项原生白板检查**：微调输出一致、读取量减少、Markdown 卡片编辑落盘、取消保存、卡片保留、文本列表与表格、撤销与重做、折叠、逐层展开、全部展开、锁定、等价规则保持位置、适应视图及保存。
- 使用运行中 Obsidian 的真实 Component 构造器，验证普通清理、迟到清理、迟到子组件加载/卸载、拒绝重载以及父组件仍按自己的生命周期清理，全部通过。此检查使用与构建相同的 Scope 源码独立打包。
- 独立移动与提交审查：30,000 次三方差分（完整旧版、隔离旧实现、当前实现），包括锁定、折叠、分组、缺失对象、并发内容和几何变化、可选尺寸标记，结果一致。
- 图模块 25,400 次差分通过；相关测试覆盖 12,000 层嵌套，主线程另独立重跑 23 项。
- 编辑独立审查：16,000 个 Markdown 上下文、1,117,112 个字数样本（含全 Unicode 码点）及 10,000 次摘录查询结果一致。
- 渲染独立审查：2,200 帧 SVG 连续差分通过；7 项真实 Component 隔离检查通过。emoji 修复采用专门预期结果，不要求与错误的旧版相同。
- 演示与实际笔记库当前白板的原文件字节保持不变；实际库设置仅最近访问时间更新。测试夹具已清除，两个宿主均未捕获错误。

资源作用域保护范围是交给 MarkdownRenderer 的本插件预览组件。第三方子组件自己的卸载函数抛错、或其自身卸载后再异步注册资源，仍可能受原生 Component 行为影响；本轮没有全局改写第三方组件。当前结果不等同于长期内存泄漏测试。
