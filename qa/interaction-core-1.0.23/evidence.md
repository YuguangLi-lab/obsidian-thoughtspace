# ThoughtSpace 1.0.23 底层优化与验证

本轮沿用已有操作，优化编辑、资料库查询、思维导图关系及连线刷新。共修改 **12 个生产模块**，新增 **36 项回归测试**（6 个新测试文件），另调整 1 个已有测试的分配计数，保留其行为断言。

比较基线是本轮开始前完整归档的 **1.0.22**，不是仍停留在 1.0.16 的 Git HEAD。既有 1.0.17–1.0.22 工作均保留。基线归档 SHA256：`33bb93a51ef2446f116aac872401dfca08cb397cbd47ad217ee1e179f5c9b92c`。

## 改了什么

### 编辑与查找

- 代码格式切换、清除格式先检查选区边界；不可能是完整代码正文时，跳过无关全文代码解析。可能匹配的内容继续由原解析器判断贪婪代码跨度、转义、跨行和空格填充。
- 行内格式、颜色与链接操作跳过无用的全文换行格式探测。列表、缩进、表格等块级操作仍继承正文 LF / CRLF。
- 整词查找直接读取两侧 Unicode 码点，省去每个候选的临时数组；选区外的字符仍参与边界判断。
- 批量替换在范围校验中累计长度变化，保持完整范围检查先于最终长度限制，保留字面替换、错误优先级及原偏移。

涉及 `markdown-edit.ts`、`editor-search.ts`。普通笔记、白板原位编辑和写作工具栏共享这些实现。

### 资料库与属性表

- 每次资料库搜索只解析一次查询；多关键词匹配复用同一对象的标题和路径文本，标签查询条件也只规范化一次。
- 批量插入已有笔记时，一次检查新增 ID 与当前白板的冲突；ID 工厂失败或冲突仍不写入部分内容。
- 属性表过滤和排序在同一次查询内复用日期有效性判断，包括非法日期结果；下一次查询重新读取最新值。搜索文字同次只规范化一次。

涉及 `space-hub.ts`、`database.ts`。没有新增跨查询的长期缓存，保留嵌套标签边界、全部范围与排序、同值排序和异常回滚。

### 思维导图与关系面板

- 关系选区仅构建此次遍历真正需要的邻接数据，空、过期和零层级选择跳过无用的连线索引；广度遍历用分层队列记录深度。
- 关系面板共享当前树索引，根节点、关系目标和来源不再逐项反复扫树。搜索仍统计全部匹配，但只保留前 80 个显示项；当前编辑目标位于前 80 项外时继续显示。空搜索不再把所有标题转小写。
- 导航、逐层展开、全部展开以及混合分组隐藏传播改为逐个入队，修复极宽分支作为函数参数展开时的 `RangeError`。

涉及 `graph-navigation.ts`、`mindmap-relations-view.ts`、`mindmap-navigation.ts`、`branch-disclosure.ts`、`mindmap.ts`。拓扑、访问次序、锁定与折叠语义保持；`mindmap.ts` 仅修改相关 4 处入队点。

### 连线与侧栏刷新

- 判定重复连线时先筛同向起终点候选，有候选再解析当前节点端口。端口直接比较两端值，省去逐候选 JSON 序列化。
- 标签内容与坐标分别比较，拖动时不再把完整长标签拼进几何键；重接手柄复用创建时引用，取消选择、离屏和清空时释放。
- 侧栏刷新逐项恢复原行的焦点，发现第二个等价控件即停止；唯一候选仍验证整个列表，避免误聚焦并保留滚动位置。

涉及 `connection-flow.ts`、`edge-layer.ts`、`sidebar-content.ts`。线条顺序、无障碍名称、标签悬停原文及现有工具栏布局保持。

### 完整行为对照

使用完整 1.0.22 与当前源码各自的依赖，比较完整返回值、异常与修改后状态，而非只检查函数名或输出片段。

- 编辑作者对照 **416,801** 次：324,794 格式计划、80,004 搜索、12,003 替换；独立复核另比较 **523,271** 次，其中 59,452 次错误结果一致。覆盖全格式命令、属性区、CRLF、转义、代码空格填充、代理对中间选区、孤立代理项、上限及错误顺序。
- 图算法作者对照 **33,160** 次；独立复核另比较 **33,460** 次，含 7,370 次错误结果一致。覆盖完整白板状态、可见集合次序、导航谓词调用次序、关系面板搜索/编辑/保存的实际渲染器快照。
- 连线与侧栏作者对照 **48,000** 次：12,000 判重、12,000 重接、4,000 完整 SVG DOM 帧、20,000 焦点恢复。覆盖端口、线型、方向、颜色、长 Unicode 标签、选择/聚焦、离屏返回、原位重排、清空与滚动。
- 资料库与属性表独立复核 **82,900** 次：37,296 匹配、25,200 全范围/排序结果、6,000 批量插入与回滚、14,404 属性筛选；保留调用顺序、输入不变和错误后完整白板状态。

独立图复核发现：普通展开路径修正后，`branchState` 的 4 处队列仍有宽分支参数展开问题。已补充完整入口回归并修复。独立执行 160,000 个直接子节点的 **7 个路径**，包括 4 种隐藏来源、导航、全部展开、逐层展开；旧版均抛出 `RangeError`，新版均完成。

160,000 子节点仅是算法边界压力，不表示可交互渲染同等数量对象，也不构成长时间无泄漏的保证。
