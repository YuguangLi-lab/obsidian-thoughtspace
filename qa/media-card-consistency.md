# 媒体摘录卡片一致性：本地阶段验证

基于 `release/1.3.26` / `b4439e9a5a358b05a92a49bea9214881d65a390f` 上继续实现，纳入 1.3.27。仅部署至同级 `thoughtspace-qa-vault`，未修改真实库。

## 已实现

白板“记下此刻”原先生成普通文本及底部媒体回源链接；截图生成独立 Markdown 卡片。独立播放器送入白板的已保存本地摘录则是原笔记块引用。现在这三种预览共用顶部时间戳、右侧来源与截图尺寸规则。

只调整渲染 DOM；保留 Markdown、原链接中的精确时间、图片节点和块引用。仅识别有效媒体协议的独立段落链接，忽略正文行内链接及包含多个候选时间戳的文档。未迁移或复制笔记数据。

时间戳路由已按用户选择统一：优先匹配当前白板或已打开的明确来源白板，无匹配或存在歧义时回退独立播放器。最终验证见 `qa/RELEASE-1.3.27.md`。

## 检查结果

- 针对性测试 65 项通过；全量 4519 项通过。两个预览测试夹具补充新增依赖 stub 后恢复通过；未以夹具问题宣称产品 bug。
- `npm run build`（包含 TypeScript 检查）通过；lint 0 错误、118 条既有警告；`git diff --check` 通过。
- 原生 Electron / Obsidian CDP，临时库，合成 MP4/PNG/Markdown/块引用夹具，28 项断言通过：三类卡片各两轮折叠展开且标题不重复；文字与截图笔记的原生实时编辑、焦点、取消；原 Markdown、引用和来源笔记不变；节点不重复；窄屏时间戳与来源无重叠、可命中、可聚焦、可悬停，完整来源路径保留在提示中。
- 宽屏窗口 1440×900，画布缩放 100%；窄屏窗口 460×780，缩放 85%。窄屏是可平移白板，不会自动重排所有节点；卡片被移至固定左侧工具栏之外测试。100% 下故意将卡片放在工具栏下方时链接会受遮挡，这不是此次新增的卡片内部重叠。
- 浅色使用原有纸张背景；暗色临时切换纯色背景以检查暗色对比度，确认宿主 `theme-dark`。结束恢复原窗口、系统主题配置与背景设置。
- 未验证新的路由目标、线上平台真实播放、第三方主题、移动端或任意缩放下的端到端可达性。
