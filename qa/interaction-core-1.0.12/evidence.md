# 1.0.12 — 搜索、拖动与会话生命周期优化

## 本轮变更

1. 搜索索引将正文与节点本地标题、路径、分组、标签分开。同次重建只归一化一次相同正文；同次查询复用正文的逐词匹配结果。相同笔记的多个白板引用仍各自保留，本地别名与正文可组合查询。元数据按文件在一次重建内共用，刷新时重新读取。
2. 无连线且不需要网格落点预览时，拖动不再生成整板临时几何；连线控制器仍逐帧调用以清理旧行和端口。存在连线或网格预览时继续使用当前拖动投影。
3. 共享编辑改变节点顺序后，拖动目标重新定位一次并更新已有位置提示；每次使用仍校验 ID、读取当前对象，删除、重新插入和同 ID 对象替换保持有效。
4. 连线几何变化时跳过未变化的选中/关系聚焦 class toggle 调用；颜色重设、直接或批量选择、聚焦改变仍正确更新。
5. 分支折叠和选择展开直接读取已有父子索引，避免计算未使用的整板隐藏状态与分组几何。锁定后代、分组内容、逐层展开及循环守卫保持不变。
6. 关闭或切换后到达的旧文件加载不能重新绑定视图；旧错误与卸载等待不能清空新会话。订阅释放幂等，关闭中的草稿仍可完成保存，退出失败可重试。
7. 保存过程中收到的文件修改事件保留到写入队列排空后复核。自身修改不产生回写循环；外部修改、无效 JSON 和后续本地写入冲突仍按原保护流程处理。

原生验证时 `document.hidden=true`。以上确认后台宿主中的功能与操作计数，不作视觉流畅度或 FPS 声明。class toggle 计数是方法调用次数，不等于浏览器实际属性修改次数；字符串处理计数也不等于总堆内存。未新增跨帧的可变白板或节点对象缓存。

保存事件修复以可靠性为主：自身写入的 modify 通知也会触发一次合并后的磁盘复核读取；这是避免保存期间丢失外部更新的明确 I/O 代价。
