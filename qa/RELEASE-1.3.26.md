# 1.3.26 发布前验收

本版从已发布的 1.3.25（`8d79f2657c1980cdd3643d5dded81e15611ba55b`）继续开发。只使用独立 checkout 和相邻 `thoughtspace-qa-vault`，没有安装到真实库、修改真实笔记或合并 main。发布采用 `release/1.3.26`，由现有工作流创建同名版本 tag。

## 实现与最后修复

- 外侧折叠控件避让附近已挂载卡片和父子节点；恢复 DOM 排序后的键盘焦点，保留独立子节点折叠。
- 固定阅读卡片密度与媒体截图、时间戳、来源信息层级打磨；仍为原笔记的实时引用。
- 文本支持六种卡片样式，保留编辑器、正文、格式、几何、连线、锁定和折叠状态。
- 最后原生失败注入发现：鼠标保存后的具体“文字、截图与记录时间已保留”提示被通用操作错误覆盖，快捷键入口正常。现已统一两个入口，新增两项按钮流程回归，并用实际 Save 按钮验证失败保留与原 ID 单条重试。

未将测试夹具缺少连线 label、宿主 manifest 缓存遗漏 dir、截图选择器匹配多个视图等测试工具错误误报为产品 bug。恢复通知测试一度只查主窗口，实际通知出现在同一临时库的独立设置窗口；确认通知存在后关闭该测试窗口并重跑通过。

## 兼容与范围

装饰文本样式需要 1.3.26 或更新版本。降级前，在新版将彩色顶栏、双线纸笺、索引卡和便签卡文本切回透明或实色并保存，保留备份。1.3.25 拒绝打开这类白板并显示错误，不静默丢弃字段或覆盖文件；本次已用实际旧版逐字节核验。

截图保留临时环境已有字体和背景。未覆盖移动端、触摸、全部第三方主题、断电、配额耗尽或多进程同库。回源验证插件处理器，不派发系统 URL。草稿暂存仅本机，仍可能丢失最后 350ms 输入或未完成写入；正式笔记仍需显式保存。未宣称性能优化，1.3.24 原始性能基线保持不变。
