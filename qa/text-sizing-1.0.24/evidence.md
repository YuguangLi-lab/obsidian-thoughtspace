# 文本框自动高度与长文阅读 — 1.0.24

## 交互

- 文本框折叠按钮右侧新增纵向双箭头开关，提示用途并提供 `aria-pressed` 状态；开启时高亮，锁定时禁用。
- 普通文本默认固定尺寸。开启自动高度后保持宽度和位置，按渲染后的 Markdown 内容增减高度；关闭保留当前尺寸。既有思维导图主题保留其自动排版行为。
- 固定文本可在框内滚动到末尾；边缘滚动不会传给画布。Ctrl / Command 缩放、表格/代码/公式局部横滚仍可用。
- 手动拖拽、匹配宽高、精确尺寸调整关闭自动高度，折叠和展开保留偏好。撤销、重做、存盘重开均保留状态。
- 新建普通空白文本使用 280 × 140 尺寸，不移动白板视角。公式、Markdown 表格及引用末尾占位继续由现有原生渲染与测量处理。

## 已复现的根因

1.0.23 在实际 Obsidian 中，320 × 160 固定文本框的正文 `clientHeight=158`、`scrollHeight=4983`，完整末尾文字仍在 DOM，但 `overflow:hidden` 裁剪正文；画布滚轮路由也未包含文本正文。新版正文 `overflow:auto` 并接入已有局部滚动路由。

旧手动文本 resize 每次重新测量并覆盖高度。回归先在旧路径失败，新版在 resize 事务中关闭自动适应，保存用户指定的两个尺寸。

自动测量统一检查文本类型、开关和主题兼容规则；异步渲染结束后重新验证宽度、模式、样式与宿主。编辑草稿已测量的尺寸在保存前再次校验，避免关闭开关或其他视图调整宽度后写回旧结果。普通固定文本不启动额外的 Markdown 尺寸渲染。
