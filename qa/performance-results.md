# 1.3.24 本地性能基线（2026-09-30）

测量在任何功能修改之前完成。基线为替换后的 1.3.24，commit `ec80f89d222f76339878414dedb680c1e862065a`，临时库部署文件与下载的该版本逐字节匹配。`main.js` SHA256：`9ef36d293ecec393e776ac3801d751a1024542d7382366daedb4ade509bbed10`。没有测用户真实笔记，也未实施保存性能优化。

## 环境与方法

- Apple M4 Pro，12 核，48 GiB；macOS 27.0 (26A428)。官方原生 Obsidian 1.13.7，Electron 39.8.3 / Chromium 142.0.7444.265 / 内置 Node 22.22.1；默认主题，独立配置与测试库。自动化驱动 Node 24.13.0。
- 窗口请求 1440×1000；实测渲染区 1440×874 CSS px，DPR 2。操作通过 Playwright CDP 连接原生 Electron 窗口，不是 Chromium 仿制 harness。
- 每档 40% 约 12.9 KB 的长 Markdown 内嵌文字（段落、表格），20% Markdown 文件引用，PDF / 图片 / 音频 / 视频各 10%，无边。20 列位置网格。合成资源为一页 PDF、320×240 两秒视频及其 PNG、两秒 WAV、100 份 Markdown。视频/音频在性能采样时未启动播放，不能代表解码压力。
- 第一组可见区域以长文本为主；第二组调整位置，将 PDF 与视频靠近首个文本节点。结束每轮操作后 DOM 节点计数分别为 6 / 13（不是整个操作期间持续可见数量，更不是 10000 个同时可见）。第二组并非所有类型同时完整显示。不要把两组差异归因为优化。
- 拖动/缩放各 1 轮预热、3 轮采样；每轮 90 次中键 pointer move、30 次 ±22 wheel（wheel 间隔 16 ms）。rAF 连续间隔含主线程与协议调度，非 GPU 呈现时间，不据此声称真实 FPS。
- 输入 3 次预热、20 次按键，测 `beforeinput` 到下一次 rAF；不含硬件输入、系统分发、像素呈现，也不含保存提交，因此不能代表端到端输入延迟。
- 保存 2 次预热、10 次原生 inline commit + Session.flush，真实临时库写入；包含编辑提交/布局/宿主写入影响，不是单独磁盘 IO。每次保存后采内存，共 10 次。未强制 GC，保留撤销历史，规模在同一进程顺序运行。p95 为 nearest-rank，10 样本时即最大值；不构成稳健尾延迟上界。
- 内存为整个渲染进程 JS heap 与 Electron private memory，非插件独占，不能与 Node 微基准 RSS 混用；无 fsync/断电持久性测试。

全部表格数值为 **p50 / p95**；时间毫秒、内存 MiB。原始逐样本数据保存在 `dist/performance-native/report.json` 与 `dist/performance-native-mixed/report.json`（忽略的本机 QA 产物）。

## 辅助微基准与诊断边界

`qa/performance-baseline.ts` 提取当前生产 Session/model，在 Node 24.13.0 中以临时文件替代 vault.process：3 次预热、20 次采样。它不含 Obsidian renderer / 索引 / 事件 / PDF 或媒体解码，不能代替原生结果。原始数据为 `dist/performance-baseline/report.json`。

| 节点数 | parse ms | 同步 change ms | flush ms |
|---:|---:|---:|---:|
| 1000 | 3.17 / 3.69 | 10.00 / 11.08 | 16.83 / 17.95 |
| 5000 | 15.00 / 16.30 | 49.07 / 51.89 | 83.46 / 91.67 |
| 10000 | 35.02 / 48.25 | 99.11 / 100.88 | 165.40 / 179.22 |

原生保存耗时随全局节点数量明显增长；辅助微基准也显示同步 change 与 flush 随规模增长。结合代码中整板克隆/撤销历史、校验、序列化路径，这是进一步 profiling 的候选瓶颈证据，尚不能把全部原生保存耗时归因到某一个函数或磁盘。建议下一阶段单独分段测量这些路径及宿主索引/重排，再判断局部更新或序列化优化。本轮未做性能优化。

这些是单机器、合成内容、无边、默认主题、较少挂载节点的结果。未覆盖第三方主题/插件、长视频并发播放、大 PDF、真实库索引负载、低端设备。原生输入到 rAF 的低数字不能推导万节点任意交互都流畅。
