# 1.3.35：便利性改动验证与操作边界

以正式 1.3.34 为基线，本轮实现原生属性同页往返、准确的保存保护状态与上下文动作、通用新建、保留想法并关联已有笔记、最近白板命令、四向脑图关系命令，以及节点直达已有笔记选择器。命名多个脑图阅读位置不在本轮范围。旧格式、现有脑图展开、中心切换、并行关系及搜索材料清单继续保留。

## 操作边界

- 新建偏好仅在成功创建并打开后启动保存。取消会阻止尚未开始的导航与偏好写入；已经开始的 Vault 写入或偏好保存仍可能完成，不自动删除已经创建的文件。
- 模板是多文件创建。部分完成后失败会停止自动重试并列出已创建文件，避免全序列重试生成编号副本；已经完成的来源文件保留。
- 已有笔记模式保留原想法整对象，新增或复用目标笔记引用节点并建立双向关系。同一对节点已有普通关联时会拒绝重复创建，提示编辑已有连线。提交与重试不读入或写回目标正文；正常内容预览仍可读取笔记。撤销/重做只恢复本次白板事务。
- 最近命令以磁盘声明和完整布局校验候选，跳过启动前已失效或损坏的记录。等待期间新导航或文件身份变化取消请求，不制造空板。取消清理不会关闭已被用户用于另一文件的标签。
- 原生往返继续核对保存、最新输入、当前 TFile/路径与多窗口所有权。状态动作只定位真实页面或打开实际恢复文件，不自动关闭未保存页、解除写保护、覆盖原文件或合并两份全文。
- 原生页已经关闭但保存标志尚未确认时继续保护布局，不能把未知状态视为已保存。恢复草稿由本地布局与此前有效文档生成，不保证已合并外部最新属性和正文。
- 四向命令无默认热键。文本输入、IME、只读/锁定、正在编辑或创建时不会执行。命令面板显示条目与关闭后执行是两次检查；恢复到文本输入焦点时仍受输入保护。
- 本轮不提供未落盘输入的强制退出恢复或跨进程草稿保证。原 1.3.34 保存和同步限制继续适用。

## 完整进程重开与输入边界

最终构建的完整进程重开通过 **34/34** 项断言，无页面或异步验收错误；使用同一专用库与配置，独立核对新进程 PID。先用真实“适应画布”菜单保存原图视口，等待整个 Session 布局与真实磁盘文件一致、稳定 600 ms，显式 flush 后再稳定 600 ms，以最终退出前新读的完整 SHA 为基准。初始到退出前仅增加预期 `/board/brainViewport`，布局区外的属性、正文及未知字段未改变。新建空脑图无额外字段变化。

分别留存进程退出、新进程加载候选前、加载后但界面重开前，以及界面重开后的完整原始文件；两个文件均与退出前基准逐字节一致。最终专用进程退出后另从文件系统读取，仍与基准一致，确认最终退出后两份文件仍与基准一致。节点身份、想法正文、旧关系、新关系、目标笔记正文及创建偏好均保留。界面重开后的 SHA 是该采样时点的观测，最终退出后的独立读另作核对。

这是所有已观察页面到达明确保存检查点后，以 SIGTERM 结束自有实例并重新启动的测试，不等同 OS Quit 菜单、未保存输入强制退出恢复、断电或物理 fsync 验收。旧的提前捕获 SHA 的失败运行和一次 QA 模块导入等待循环被保留，未计入成功结果；最终脚本没有删除视口字段以绕过完整文件检查。

附加原生 CDP IME 探针收到可信 `compositionstart`/`compositionupdate`，组合期间真实关系快捷键没有打开创建弹窗，也未改变节点或关系。`Input.insertText` 提交后宿主/CDP 返回的 `compositionend` 为非可信事件，因此等待可信结束超时，后续正常输入和结束后关系创建未执行。该探针**不算完整通过**，不声称已覆盖 OS 输入法或所有键盘布局的完整开始/提交/结束流程；自动回归及其他真实键盘操作结果单独保留。
