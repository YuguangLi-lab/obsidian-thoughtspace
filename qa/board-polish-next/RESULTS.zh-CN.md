# 白板与卡片体验验收

日期：2026-09-30。基线：正式版 1.3.23。
状态：本轮开发优化，尚未发布新的正式版本；未修改真实 Obsidian 仓库。

## 已确认并修复

| 问题 | 修复与证据 |
| --- | --- |
| 卡片编辑 Ctrl/Cmd + Enter 无法保存退出 | 正式安装包在正确窗口焦点下复现宿主提前消费保存键。仅接管当前编辑器的保存快捷键，退出后释放，不改 Esc 行为。 |
| 淡出中的操作条误拦邻卡点击 | 原状态失去悬停后仍在透明动画阶段接收点击；现在收起时立即停止命中。保留可见按钮、键盘焦点和触屏操作。 |
| 双线纸张卡片没有锁定提示 | 纸张装饰与锁定标识使用不同伪元素，边框与锁定提示同时保留。 |
| 少量连线的大白板反复扫描全部卡片 | 缓存索引位置，每次验证当前节点 ID，必要时重建；不缓存旧节点对象。密集连接保留线性索引。 |
