# 白板与卡片体验优化预览

这是基于正式版 1.3.23 的本地开发预览，不是新的 GitHub 正式版本。
清单版本暂保持 1.3.23，避免占用下一次正式发布的版本号。

## 安装与回退

1. 先备份仓库及 `.obsidian/plugins/thoughtspace` 整个插件目录。
2. 关闭 Obsidian，解压预览包中的 `thoughtspace` 文件夹。
3. 只替换目标插件目录中的 `main.js`、`styles.css` 和 `manifest.json`。
4. 保留原有 `data.json`，不要删除设置或覆盖笔记文件。
5. 重新打开 Obsidian，先在测试白板检查常用操作。

需要回退时，关闭 Obsidian并恢复备份的三个运行文件。此预览不迁移
白板或 Markdown 格式；正式版 1.3.23 的安装包和 GitHub Release 保持不变。

## 本轮重点

- 修复 Ctrl/Cmd + Enter 被宿主提前拦截，无法保存并退出卡片编辑的问题。
- 减少大量卡片、少量连线的白板在平移时重复扫描全部卡片。
- 恢复双线纸张卡片的锁定标识，同时保留纸张边框。
- 防止淡出中的旧卡片工具条拦截邻近卡片的点击。

自动化验收使用独立的 Obsidian 配置和生成的测试笔记，不触碰实际仓库。
覆盖拖动、缩放、尺寸调整、撤销、阅读滚动、展开折叠、明暗主题、窄窗格、
编辑保存、失败恢复及输入法组合输入事件边界。真实中文输入法、其他主题
及第三方插件组合仍应在备份后的测试仓库中验收。
