# 1.3.36 验证摘要

1.3.36 已完成正式本地检查与隔离原生复核。插件实现及 main.js／styles.css 与完整功能候选逐字节一致，manifest 使用正式版本号。功能候选的 24 组验收与本次正式复核分别列出，不重复累计。公开 CI 与发布下载是独立阶段；本地通过不代替 GitHub Actions 的实际结果。

## 功能范围

- 独立手写白板：整笔擦除、撤销重做、整笔套索与移动／复制／删除、SVG 附件导出及来源回链。保存异常时只读对照磁盘、本地和恢复版本，不自动合并或覆盖。
- 脑图阅读位置、每张引用卡片的定位与返回、快速收集到指定白板／分组，以及可选的保持簇内几何整理。低缩放选中操作放在画布之外，大笔迹分帧显示并保留完整源采样。
- 收集页：正文优先的原生 Markdown 记录、标签和已有附件、可选投递、创建时间流、独立草稿检查点及固定身份恢复。旧笔记不被自动回填收集属性。
- 收集与普通／独立脑图／嵌入脑图的双向定位，核对具体引用实例；改名、删除、同路径替换、迟到回调、侧栏及弹出窗口有独立保护。
- 普通白板、脑图、手写、收集、媒体、在线、写作、阅读、材料、PDF、设置和弹窗的主题与容器布局统一；保留原生编辑、播放器、草稿和多窗口保存所有权。
- 已公开的一期 [AI 白板 CLI](https://github.com/YuguangLi-lab/obsidian-thoughtspace/blob/1.3.36/docs/AI-BOARD-GUIDE.zh-CN.md)继续独立提供只读检查与排他创建。它使用 Node 22，不向插件移动运行时加入 Node 依赖；本版本不新增 npm 或 MCP 发布，也不自动调用 AI 服务。

## 实际交互与恢复

- 普通卡片正文滚动与卡片拖动分开，编辑、取消、连点、新导航、保存后重开及新进程恢复分别核对。原生 Markdown／Properties 编辑和多窗口保存保护保留。
- 收集故障覆盖受控临时写拒绝／部分写、正式写入拒绝／损坏、创建落盘却返回错误、重复提交与新进程草稿恢复。结果未知时保留输入并停止自动重建。不能据此承诺物理断电或任意文件系统故障可恢复。
- 双向定位覆盖同一来源的多个板／节点、第三页与长预览返回、筛选隐藏记录的临时显露、独立／嵌入脑图、改名／删除／同路径替换、真实侧栏活动页面和弹出窗口。主窗及弹出窗口首次打开目标都核对所属窗口，不抢另一窗口的输入。会话内浏览位置不等于跨进程持久化承诺，也未穷举每种窗口、尺寸和生命周期的组合。
- 本地自制视频实际解码、播放到结束、时间定位、截帧并核对 PNG 落盘；本地音频、阅读、写作、材料投递与保存回执也有实际操作。原生 PDF 验证页面 canvas 与可读文本层。外部在线视频站点、账号、网络播放及全部编码器未验。
- PDF 短屏输入使用真实键盘导航、输入与滚轮：末尾输入后的滚动值为 85／93／199（scrollTop／clientHeight／scrollHeight，底部 padding 18），滚轮可达 106／93／199，光标仍在 78；Meta+↑ 回到开头，恢复文本并取消后磁盘字节不变。自动滚动留有底部 padding 不等于字符丢失。这不是系统 IME 验证。
- 长笔迹使用两份独立样本：65,520 点源上的 17 点未提交草稿经 resize 保留；释放时超出 65,536 点预算，提交被拒绝，原源文件与笔迹保留，**被拒草稿清空**。另一份 65,280 点源才用于 16 次草稿、48 次 resize、12 次提交／4 次取消、新进程重开及一次受控最终写入失败后的恢复文件核对。不能把两份样本合计成一次负载，也未把此检查扩大为备份双失败、重试或崩溃恢复全覆盖。

## 尺寸、性能与移动加载边界

候选在桌面 Obsidian 隔离环境综合检查 360／390／430 手机宽度、768／820／1024 平板宽度、横竖屏、384／410／512 分屏、可见键盘高度 380 及 285 极短窗口，包含浅深主题、CDP touch、明确标注的合成 pen 和 visualViewport 模拟。各组的尺寸与操作不同，不能解释为每个页面、每种功能、每个尺寸均完整遍历。

1,000 条收集记录在暖桌面环境打开 164 ms、筛选 58 ms、翻页 69 ms，初次 8 次正文读取涉及 4 个唯一文件；1,000 节点合成脑图打开约 628 ms，投影上限为 72 个节点。时间包含自动控制、存储、渲染和帧等待，只是该样本和桌面机器的观测，没有手机延迟、FPS、低端设备或长期无泄漏保证。脑图 DOM 数量不等于源文件读取量。长笔迹显示优化保留全精度源数据；可导航、可编辑、可见部分显示完成和全图显示完成是不同阶段。

无 Node 探针在 iOS／Android Platform 标记、`isDesktop=false` 的独立 VM 中执行原样模块并构造插件；Node／Electron 入口被硬拒绝，候选未请求这些入口。探针使用宿主 API 替身，**未执行 `onload`、真实移动初始化、UI、存储或移动 WebView**。

**尚未验证：** 物理 iOS／Android、Apple Pencil、WKWebView／Android WebView 初始化、系统移动 IME、真实软键盘、完整掌拒、硬件压力／延迟和设备性能。不承诺 Pencil 双击／悬停、PencilKit 或 OCR。

桌面宿主 1.14.4 的诊断曾出现快速 resize 后立即关闭设置窗口时的 `getZoomFactor` 旧窗口代理竞争。最终候选组在视口稳定后正常关闭，没有屏蔽错误，也没有宣称修复了宿主竞争。
