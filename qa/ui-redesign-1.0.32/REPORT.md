# ThoughtSpace 1.0.32 布局改版与验证

完成日期：2026-09-26。构建、安装、重新加载和运行文件哈希校验完成；日常库与测试库均为 1.0.32。本轮未上传 GitHub 或发布 Release。

## 改版结果

- 侧栏在宽度至少 280px 时采用纵向栏目导航，搜索和结果放在右侧；更窄时切换为横向四栏目。收集、新建、空间总览、摘录、整理白板和分组预览入口保留。
- 空间总览改为内容优先的资料库：放大白板缩略图，详情按需展示，提供直接打开按钮，分别显示画廊/列表入口，筛选与排序集中收纳。
- 查看详情不再重建结果列表，保留滚动位置；返回时恢复入口焦点。窄窗详情替换内容区，避免键盘进入被遮挡控件。
- 整理白板采用独立参数栏、大预览和固定底部操作。分组总览改为双列大缩略图，窄窗使用图文条目；移入分组重新划分列表和预览区。
- 修复整理窗口的预览缩放按钮、移入分组的图例/说明在矮面板中被裁切的问题。修改原滚动容器，不改排版算法。

延续 Obsidian 的界面/正文字体、透明卡片和主题设置，未改变节点内容或存储格式。生产源码涉及 6 个文件，新增一个聚焦真实交互的测试文件。
