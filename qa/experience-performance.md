# 1.3.27 候选：原生保存分段与小地图复用实验

使用现有独立 `thoughtspace-qa-vault`，Apple M4 Pro / 48 GiB / macOS 27，原生 Obsidian Electron 39.8.3 / Chromium 142，驱动 Node 24.13.0。不是 Chromium 仿制页面。运行时版本和逐样本数据在忽略目录 `dist/experience-save/`；基于 1.3.26 的未发布候选，首轮前后均显示 manifest 1.3.26。1.3.24 基线未改动。

## 方法

- 沿用合成 1k/5k/10k 节点混排文件：40% 长 Markdown 文本、20% Markdown 引用、PDF/图片/音频/视频各 10%；无连线。种子先固定保存，每阶段从同一份种子重置临时文件。媒体暂停。
- 窗口 1440×900；开始编辑后每档实际挂载 **2 个节点**。不是一万节点同时显示，也不是视频解码压力测试。
- 每档预热 2 次，采样 10 次。每次原生实时编辑器追加字符，测 `inline.commit()` 到 `Session.flush()`；保留真实历史、完整序列化、冲突检查及 `vault.process` 原子写入。没有强制 GC，同一进程按规模递增运行。p95 使用 nearest rank，10 样本时就是最大值。
- 包装生产方法记录 change/history/emit/process。区间会重叠，不能简单求和；process 包含宿主事件和主线程调度，不代表纯磁盘 IO。另保存 CPU profile；完整 profile 包含打开编辑器，`save-only.cpuprofile` 仅覆盖提交/flush。
- 当前临时环境还包含辅助 ThoughtSpace Calendar（CPU profile 中可见其回调）；没有将插件成本与宿主或辅助插件成本完全分离。实验期间没有新增或切换插件。
- 未重测拖动 FPS、端到端输入延迟、媒体并发播放或真实库负载。内存仅为该渲染进程 JS heap，不是插件独占。

## 首轮端到端保存（毫秒，p50 / p95）

| 节点 | 改前 | 候选改后 | p50 变化 |
| ---: | ---: | ---: | ---: |
| 1,000 | 329.7 / 352.0 | 370.7 / 425.2 | +12.4% |
| 5,000 | 766.5 / 1022.5 | 750.3 / 802.1 | −2.1% |
| 10,000 | 1677.7 / 2112.7 | 1523.3 / 1764.6 | −9.2% |

10k 改前分段 p50：change 186.7 ms（包含 history 45.5 ms 与部分通知），process 943.9 ms。改后分别为 184.5 / 44.4 / 756.3 ms。不能把 process 差额全部归因到磁盘或小地图。

保存专用 CPU 采样显示 `mapPreview` 有约 345 ms 自身采样时间。代码确认单张卡片高度变化会使小地图 key 变化并重建全部 SVG。候选只在节点/边顺序、种类与配色保持一致时复用 SVG，更新变化几何；结构、折叠可见性或样式变化仍重建。边界变化同步更新节点、边和视口映射。**没有删减校验、历史或更改磁盘写入算法。**

## 同一候选的交替对照

为区分首轮顺序/GC 波动，另用同一候选、同一会话和历史，交替 AB/BA：A 仅关闭小地图复用，B 开启；每条件 2 次预热、10 次采样。

| 节点 | 条件 | 整次保存 p50 / p95 ms | 小地图阶段 p50 / p95 ms |
| ---: | --- | ---: | ---: |
| 1,000 | 关闭复用 | 411.4 / 508.4 | 18.7 / 21.2 |
| 1,000 | 开启复用 | 446.5 / 571.8 | 0.5 / 21.2 |
| 10,000 | 关闭复用 | 2378.3 / 2931.0 | 354.6 / 393.2 |
| 10,000 | 开启复用 | 2170.0 / 2948.3 | 5.5 / 378.0 |

开启复用时小地图重建次数 p50 为 0、p95 为 1；关闭时均为 1。因此复用命中时重建工作明显减少，但布局变化仍可能触发重建。10k 整次保存 p50 改善约 8.8%，**p95 未改善；1k 两轮都没有观察到端到端收益，反而更慢**。这是有限样本单机结果，不是所有规模提速的证明，不承诺小板或尾延迟收益。全局编码、历史、宿主处理及 GC 仍占成本。

## 复现与证据

- `qa/experience-save-native.cjs`：首轮前后相同条件流程。
- `qa/experience-save-paired.cjs`：同一候选交替开关小地图复用。
- `dist/experience-save/{before,after,paired}.json`：全部样本与摘要。
- `dist/experience-save/{before,after,save-only}.cpuprofile`：CPU 证据。
- `dist/experience-save/seed-*.json`：相同种子，仅合成内容、不进入 Git 或发行包。

单元回归验证复用节点身份、只写变化属性、撤销替换对象、边界变化、边与视口定位，以及折叠/显隐/类型变化的正确失效。既有保存队列、外部冲突、失败恢复及 undo/redo 测试继续运行。
