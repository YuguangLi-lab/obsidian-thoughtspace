# 1.0.21 — 思维导图、Markdown、布局预览与测量生命周期优化

以完整备份的 **1.0.20 实际源码**为基线，保留前轮尚未提交的改动，没有用 Git HEAD 代替当前版本。本轮修改 **12 个生产模块、8 个测试文件，新增 33 项测试**，没有新增生产依赖或改变白板数据格式。

**2,602 / 2,602** 全仓测试通过，无跳过；TypeScript 与生产构建通过；ESLint **0 错误、79 项既有警告**；发布脚本测试 **7 / 7 通过**。

## 改动范围

| 路径 | 本轮实现 |
| --- | --- |
| `markdown-context.ts`、`markdown-literals.ts` | 注释候选位置按前进方向查找，避免在长行每个字符上重复探测；保留代码、转义、跨行注释、元数据及偏移语义。 |
| `writing.ts` | 多个分散分组组装草稿时复用本次操作的空间查询；单组、密集重叠/嵌套组保留直接查找，重复显式组引用不重复展开。 |
| `mindmap-editor.ts`、`mindmap-branches.ts`、`mindmap-auto.ts` | 展开深度、自动排版配置、关联线编辑共享一次命令内的已校验主题索引；修改后的排版和最终白板校验继续执行。 |
| `mindmap-sizing.ts` | 逐行累计最大宽度，修复超多行文本在参数展开处触发栈溢出；换行、折叠与字体计算保持。 |
| `inline-card-fit.ts`、`inline-text-fit.ts` | 过期稿件立即释放原生测量组件与测量 DOM，迟到注册的资源仍立即清理；识别直接 MathJax 容器，等公式排版完成再测量。 |
| `card-preview.ts` | 存在公式时等待公式布局完成再触发就绪/自动适配，取消和超时仍受同一个总截止时间约束；普通 Markdown 不增加公式等待。 |
| `board-reuse.ts`、`layout-planner.ts` | 批量复用按不同来源路径统计已有引用；布局预览减少散卡与分组的重复扫描，保留小选择、密集分组和原子应用保护。 |

索引与扫描状态均限于当前操作，未新增跨编辑持久内容或几何缓存。

### 重叠、离群框与小选择的权衡

独立复审发现，直接对每个框建立成员结果会拖慢密集重叠场景；仅按已处理内容比例回退，也会伤害分散框。最终实现采用重叠密度回退，并在索引查询确实大量重复命中已归属内容时，改查剩余对象；全部归属后停止。

以下为另一组独立计数，输入为 1,024 个内容对象：

| 几何分布 | 旧几何读取 | 新几何读取 |
| --- | ---: | ---: |
| 64 个分散框 | 319,712 | 33,383 |
| 64 个重叠框 | 12,288 | 12,800 |
| 63 个重叠框 + 1 个远离框，内容全在首框 | 12,288 | 46,630 |
| 上一场景另含 64 个散卡 | 44,672 | 93,168 |

离群框场景仍承担索引构建和首次探测代价，**不是所有布局都比旧版读取更少**。最终处理消除了初版约 173 万次反复扫描已归属内容的数量级回退。少量笔记复用保留原先的早停查找，重复引用按每个来源实例计数，不改变结果。

## 具体修复与回归保护

- **超多行文本无法自动适配**：150,001 行现有文本在旧版触发 `Maximum call stack size exceeded`；现在宽度 80、高度 4,080,058，完整自动排版命令也可完成，源对象不变。
- **连续输入保留过期测量组件**：新稿接管时直接关闭旧测量组件与 DOM，旧稿的迟到清理/子组件注册不再等待其渲染完成；当前稿保留自己的完整截止时间。
- **公式未完成排版就适配尺寸**：卡片预览和两类行内测量覆盖 `.math` 与 `mjx-container`，公式完成前不提交尺寸；等待不会重新延长原截止时间。
- 缺失端点、循环、多父级、锁定、混合分组包含关系仍按原规则拒绝；未改变兄弟顺序、折叠状态和手动布局语义。
- 布局计划仍在全部验证后才写入；预览后尺寸、锁定、分组成员或外部对象变化继续触发拒绝。
