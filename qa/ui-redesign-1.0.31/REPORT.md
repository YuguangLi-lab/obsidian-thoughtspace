# ThoughtSpace 1.0.31 界面改版与验收

完成日期：2026-09-26。已构建、安装并重新加载至测试库和日常使用库；本轮未推送 GitHub，也未发布 Release。

## 改版内容

- 知识空间侧栏重新分区：顶部集中收集与新建入口；卡片、白板、任务、大纲采用分区导航；整理白板与分组预览固定在底部。内容区独立滚动，矮窗口自动压缩导航布局。
- 顶部编辑栏改为单行悬浮布局，保留 Markdown、文字、背景、边框及样式复制应用。窄窗口可横向滚动并通过方向按钮访问完整控件。
- 画布设置放在左下，缩放与总览放在右下；中间留空区域可以直接操作画布。
- 插入与更多工具面板重绘，增加整理、思维导图、工作区快捷定位。矮窗口暂时让工具面板使用更完整的画布高度，关闭后恢复底部控件。
- 修正两列导航上下方向键、菜单关闭状态和筛选提示的位置，缩短画布悬停提示。

用户的 Obsidian 字体、透明卡片和背景偏好保留。已有文本自适应关闭修复继续保留。
