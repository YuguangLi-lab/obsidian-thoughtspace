# 1.0.18 — 白板交互、编辑与资源调度优化

基线为本轮开始前保存的完整 **1.0.17** 源码，包含前一轮尚未提交的改动；没有使用 Git HEAD 代替基线。

全仓 **2,518 / 2,518** 测试通过，本轮新增 **31 项**。TypeScript、生产构建、发布元数据校验及 **7 / 7** 发布脚本测试通过。ESLint 为 **0 错误、79 项既有警告**。

## 实现改动

1. 新建、撤销、查找等全局快捷键的可用性判断不再读取整板选中节点；编辑、关闭和失效会话保护仍先检查。
2. 折叠命令在同次判断内共享轻量父子关系，避免逐个图片重复构建；空选区跳过扫描。
3. 批量连线筛选先判断是否属于选区范围，再按需解析可编辑端点。
4. 批量连线改色等修改在确实存在目标连线时才检查端点，仍优先拒绝无效参数，并保留锁定与折叠保护。
5. 分组关系验证从进入分组的分支开始遍历，按需查询可达组成员，保留普通循环与混合包含循环检测。
6. 完全展开的思维导图布局不再创建隐藏后代的位置快照和位移映射；存在折叠后代时沿用完整搬移逻辑。
7. 行内代码直接定位反引号，普通文本跳过不存在的隐藏注释解析，保留代码和注释边界。
8. 代码格式围栏长度逐段计算，移除超大数组参数展开。
9. 写作顺序校验仅收集对象标识；草稿按指定顺序取材，只对实际展开的组内材料做几何排序。
10. 折线生成同步收集有效路径点和段长，减少过滤、切片和映射数组。
11. 节点渲染标识直接构建所需字段，保留未知自有属性、字段顺序及特殊属性的序列化结果。
12. PDF 池记录闲置文档数量，没有可淘汰文档时跳过扫描；释放、失效替换、失败和关闭仍正确清理资源。

本轮没有改变存储格式，也没有增加跨操作的正文或几何缓存。

## 已复现并修复的异常

450,000 字符、含 150,000 组反引号的文本，旧版执行行内代码和代码块格式操作都触发 `RangeError: Maximum call stack size exceeded`。新版两个入口均成功，保留文本、选区和替换结果。这是同类参数上限问题的两个入口，不按两个独立缺陷计数。
