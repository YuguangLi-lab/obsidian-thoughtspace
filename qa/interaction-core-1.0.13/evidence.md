# 1.0.13 — 连线、批量主题与编辑测量优化

代码验证、原生 Obsidian 前后对比及 17 项操作回归均已通过。本地已安装 1.0.13，安装包与数据完整性已核验；本轮未上传 GitHub。

## 本轮变更

1. 侧栏提取已打开白板的子板链接时直接同步读取当前会话，避免为只读提取深克隆正文和写作草稿。普通 `readBoard` 仍返回独立可编辑副本；链接去重和顺序保持不变。
2. 连线行改为直接比较几何与样式字段，未变化时不再构建数组并拼接字符串；端点索引仍逐帧重建，直接填充 Map，省去临时键值对数组。节点移动、同 ID 对象替换、撤销、离屏移除及选择状态仍读取当前值。
3. 完整白板刷新中的统计文字只遍历一次节点，替代五次按类型筛选。显示文字及导航交互保持不变。
4. 批量创建同级主题时，按原顺序完成节点测量与编号生成，再一次插入分支边，避免每个主题重建连线数组。原有关系边、附加属性、锁定检查、失败回滚与五种布局保持不变。
5. Canvas 导出在一次调用内逐步建立端点索引，避免每条边重复查找整张节点表。少量、靠前的端点只索引所需前缀；重复 ID 仍使用首个节点。
6. 卡片编辑只复用最近一次成功的普通静态段落测量。正文、布局环境、引用占位或父容器变化时重新测量；富 Markdown、动态输出及失败结果不复用。缓存随编辑器销毁释放。
7. 卡片和文本编辑的新版本到达正常防抖时点后，停止等待旧尺寸并移除其测量容器，使新草稿不必等旧任务超时。同版本并发调用仍共用测量；旧渲染或公式回调不能覆盖新尺寸。尚未完成的旧渲染组件保留到渲染完成或原有 1 秒期限，使异步注册的资源仍能得到清理。

原生采样时 `document.hidden=true`。操作计数和复制字符数不等于实际分配字节或内存峰值，不作视觉流畅度、FPS 或内存峰值改善声明。840 ms 等待来自受控时钟，不是原生计时结果。
