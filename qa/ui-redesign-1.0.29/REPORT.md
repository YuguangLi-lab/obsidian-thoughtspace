# 1.0.29 UI 重排与验收

本次沿用 Obsidian 原生字体和主题变量，重排整理白板、搜索白板和底部画布控制。未更换编辑引擎或布局算法。

## 实现

- 整理窗口：范围置顶，8 种常用布局以图示和短说明呈现；高级对齐、等距、预设分层收纳；扩大实时预览，保留原布局比较、16 种算法及应用后撤销。
- 搜索窗口：完整搜索栏，宽屏左侧筛选/右侧结果，窄屏上下布局；对象类型、分组、颜色有可见标签，结果按标题、摘要、来源层级呈现。
- 画布：吸附、网格间距、背景、缩放、适应和总览整合为一个底部控制栏；窄窗分行，使用实际高度为其他控件预留空间。总览开关使用原有持久设置，关闭时释放缩略图内容。
- 编辑条：短分屏中保持按钮单行，次要状态标签让位，保存、取消、复制和搜索按钮不再被裁切。
- 搜索交互：静止鼠标触发的边界事件不再覆盖键盘选择，只在鼠标实际移动时更新当前结果。
