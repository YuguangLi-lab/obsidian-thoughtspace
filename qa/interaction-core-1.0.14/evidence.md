# 1.0.14 — 缩略图、连线路径与导图计算优化

## 变更

- 缩略图一次遍历完成边界、端点索引和绘制分组；长正文标题只处理所需前缀。缓存键补入节点类型，修复几何不变而类型变化时缩略图样式未更新的问题。
- 连线两端均指定端口时跳过自动方向计算；折线路径的相邻段长度只计算一次，供圆角与标签位置共用。
- 批量导入大纲时，在本次操作内读取一次根主题的自动适配设置；按连线布局时，聚类与预览签名共用本次端点对。失败顺序、原板隔离及应用前的过期检查保持不变。
- 两个摘录正文入口在没有 `来源：` 标记时跳过逐行解析，保留换行归一化；有标记时继续原解析流程。
