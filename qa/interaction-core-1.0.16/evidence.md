# 1.0.16 — 控件、连线与导图计算优化

本轮完成七处优化，全仓测试 **2,459/2,459** 通过，新增 **18 项**；TypeScript、生产构建、发布元数据及 **7/7** 发布脚本检查通过。ESLint **0 错误、79 项既有警告**。

## 七处变更

1. 控件刷新在没有选中节点或连线时，省去无用的整板查找。
2. 控件属性与实时 DOM 比较，只写变化项；外部修改或重挂载后仍及时恢复正确状态。
3. 离屏连线在边界结果已确定时停止后续几何计算，保留跨越视野的连线和原浮点比较顺序。
4. 自动主题的备用尺寸计算直接迭代 Unicode 字符，省去逐行临时字符数组，保留尺寸结果。
5. 导图 SVG 的路径与标签共用本条边的一次路由结果。
6. 概念选区只消费到选中行的 Markdown 上下文；仍传入完整原文，保留 frontmatter 前瞻与围栏保护。
7. 引用片段多词搜索只转换一次候选文本；空查询直接保留当前选择。

这些路径没有新增跨操作内容或几何缓存。锁定、折叠、顺序、冲突检查及原有源数据隔离保持不变。
