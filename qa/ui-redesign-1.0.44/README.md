# 1.0.44 主界面布局改版

本次重排白板导航、对象编辑栏、画布控制条，并保留 Obsidian 的原生字体和主题。

## 实现

- 侧栏宽度达到 300px 时，四项内容导航改为左侧纵向排列，搜索与内容索引位于右侧；小于 300px 时使用紧凑横排。底部整理白板、分组预览保持固定。
- 顶部编辑工具栏在宽画布合成单行，以图标和当前值显示属性；窄画布分为两行。原生选项框、滚动箭头、Markdown 命令和分区键盘导航保留。
- 背景、网格、对象状态、缩放和总览整合到居中底栏；窄窗口使用横向滚动，避免堆叠遮挡画布。创作工具栏收紧到 50px。
- 修正纵向导航的无障碍方向声明，ResizeObserver 按真实布局更新 aria-orientation，关闭视图时释放观察器。

## 验证

- 构建、类型检查通过；3,155 项自动测试全部通过，其中新增 5 项导航测试。
- ESLint 为 0 错误、82 项既有警告；发布元数据检查及 7 项发布工具测试通过。
- 182 组浏览器布局回放通过：侧栏 34、顶部工具栏 96、底栏 52；底栏额外检查 468 次控件焦点显示与点击命中。
- Obsidian 原生界面检查：107 项画布布局/滚动检查、40 项侧栏切换检查、25 项卡片/分组/混选/连线/原生 Markdown 编辑检查，以及 9 组编辑器尺寸与缩放组合，全部通过；另验证编辑器焦点、保存撤销及取消清理。
- 检查过程中未捕获 Obsidian 运行错误。浅色和深色实际截图已目视审阅。

## 测试证据边界

浏览器回放使用真实 DOM/CSS，部分 Markdown、混选、连线状态使用既有 DOM 或匹配生产结构的 fixture；本轮另在 Obsidian 内对真实状态进行了检查。后台窗口的程序化 focus 不派发 focusin，首次焦点断言因此失败；经确认 document.hasFocus=false 后，测试在该条件下显式重放 focusin，方向键处理则直接触发真实事件监听器。这不是已确认的插件缺陷，也未据此修改焦点生产逻辑。没有进行长时间性能压测。
