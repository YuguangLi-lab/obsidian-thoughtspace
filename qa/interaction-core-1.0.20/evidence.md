# 1.0.20 — 编辑事务、分组、长文处理与连线层级优化

以完整备份的 **1.0.19** 为基线，保留前轮尚未提交的改动，没有使用 Git HEAD 代替当前版本。本轮修改 8 个生产源码文件，新增 20 项回归测试，没有增加生产依赖或改变数据格式。

**2,569 / 2,569** 全仓测试通过，无跳过；TypeScript、生产构建、发布元数据以及 **7 / 7** 发布脚本测试通过。ESLint **0 错误、79 项既有警告**。

## 改动

- 普通编辑、移动保持连线次序时，省去旧连线 ID 集合的重复构建；新增和重排仍正确处理默认样式与单条连线样式。
- 撤销历史超出预算时，仅统计一次两栈大小，随后按实际删除量扣减；保留原淘汰顺序、最低一条快照和外部直接修改历史栈的行为。
- 暂停写入的白板拒绝编辑前，不再复制整板；正常事务仍保留锁定检查、回滚、历史与保存冲突保护。
- 分组总览复用本次操作的空间查询，并一次统计成员类型；维持原白板顺序。移动方案去掉重复的折叠后代展开，仍整体检查隐藏、锁定、循环及目标障碍。
- Markdown 清除格式记录已确认未闭合的括号，反斜杠按奇偶线性扫描，减少畸形链接和长转义串的重复处理。
- 白板搜索标题仅读取首个非空行；空查询摘要只规范化够显示的前缀，避免整篇长笔记拆分。非空查询保持原检索语义。
- PDF 文档池只从空闲候选中选择淘汰项，保持按获取顺序的 LRU、活动租约保护、超时与关闭清理，不增加文档或画布缓存。
- **修复连线层级错误**：连线被视野剔除后重新出现，或原地重排连线数组时，SVG 绘制和点击层级会同步恢复白板顺序。已有路径、标签和手柄继续复用，稳定帧不额外重排 DOM。

- 独立编辑复审：20,000 个清除格式、15,400 个摘要、12,000 个索引结果与旧版一致，覆盖嵌套/未闭合链接、转义、代码、CRLF、分块空白及 UTF-16 边界。
- 独立分组复审：5,000 个目录、30,000 个筛选排序、9,000 个方案结果一致；4,369 个有效方案实际应用后也一致，覆盖隐藏、锁定、混合循环、折叠单元重叠及并发编辑拒绝。
- 独立事务复审：10,080 次历史转换、8,000 个连线样式案例、288 个事务组合验证通过；暂停状态仅省去预期的无用复制。
- PDF 作者差分 48,000 次操作通过；另独立验证 5,280 个状态、79 次顺序计数重置，覆盖加载/销毁异常、退役/重新获取、超时和关闭，未发现悬空记录。
- SVG 作者差分 3,000 帧、独立差分 3,600 帧通过；除本次修正的根级绘制顺序外，内容一致。独立检查包含 400 个全部可见、持续重排的帧。
- **17 项原生白板检查通过**：事务输出与工作量、Markdown 卡片落盘/取消、卡片保留、文本列表和表格、撤销/重做、折叠/逐层展开/全部展开、锁定、等价规则保持位置、适应视图和最终保存。
