# 单行文本框缩小修复 · 1.0.36

用户要求：只有一行文字时能压缩底部空白，最小高度为 40 像素。

## 原因与修改

- 手动缩放函数把文本按笔记卡片的规则限制在 100 像素；已有矮文本在仅调整宽度时也会被撑高，Shift 等比缩小时可能反而变大。
- 文本手动最小高度改为 40；解析、保存、精确尺寸、折叠恢复和尺寸队列采用相同的文本边界。普通卡片、图片、PDF 和分组保持原规则。
- 缩短文本时，根据字号和边框收拢上下内边距，预览与原生编辑器共用；保留正文的字体、字号和长内容内部滚动。自动适应高度仍是显式开关。

## 验证

- 修复前 6 个新增拖动回归场景失败；最终完整测试 2905/2905 通过。
- TypeScript 与构建通过；ESLint 0 错误、82 项已有警告；安装包与发布元数据校验通过，7 项打包测试通过。
- Obsidian 1.13.7 实际鼠标拖动：文本从 100 缩到 40；保存与插件重载后仍为 40。
- 默认 16px 正文字号、1.7 倍行高下，上下内边距各 5.4px；正文 clientHeight 与 scrollHeight 均为 38px，单行未裁切。原生编辑时同为 40px，内边距及字号一致。
- 验证撤销/重做、文本折叠展开、子节点折叠展开、编辑取消和保存、自动高度开关；白板视角未发生变化。
- 已备份并安装 demo-vault 和主库；六处运行文件哈希一致。主库原白板 37 个节点及演示原白板内容未改动；临时复现白板验证后移入回收站。

边界：40 是手动框高下限。大字号或多行内容仍需较大高度或内部滚动，开启自动高度会按内容撑开。
