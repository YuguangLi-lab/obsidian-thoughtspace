# 1.0.15 — 编辑解析、框选与布局计算优化

七处优化已完成生产函数回归、整仓构建、发布检查和 16 项原生检查；demo 与实际笔记库已部署 1.0.15。

## 七处变更

1. 笔记库的同步标签统计和筛选共用一次元数据读取；异步正文读取后，行标签仍读取最新数据。
2. 框选直接收集结果；折叠场景先取得精确几何候选，再计算必要的可见性，保留显示尺寸、完整包围和选择顺序。
3. 对齐吸附找到零距离时停止重复搜索，保留首次胜出目标和原并列规则。
4. 标题布局在单次排序中按对象身份提取一次标题；源签名和应用前校验继续独立计算。
5. 可见布局范围先筛视野候选，再检查分组包含关系，每次都读取当前折叠和分组状态。
6. Markdown 普通行在无活动注释、无潜在注释标记时跳过逐字符遮蔽；代码、转义、注释续行和围栏继续原解析路径。
7. 非整词查找跳过不需要的 Unicode 邻接字符提取，保留匹配范围及原有输入限制。

这些改动不增加跨操作索引或长期内容缓存。
