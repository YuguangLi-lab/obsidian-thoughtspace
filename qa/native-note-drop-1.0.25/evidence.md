# 原生笔记拖入白板 — 1.0.25

## 行为

- 从 Obsidian 文件列表、搜索结果或可拖动的内部链接，把已有 Markdown 笔记拖到白板落点，生成关联卡片，原笔记保持原位。
- 多选文件保留顺序，一行最多三张卡片，整批全选、单次撤销；重复拖入同一篇笔记允许创建新的引用，同一次拖入的重复引用合并。
- 沿用现有 PDF 卡片、文字和 PDF 摘录、插件自身笔记/子白板拖动及外部附件导入；不扩大任意普通文本的拖入识别范围。
- 同步阻止父级打开笔记并允许事件冒泡供原生拖拽清理。保存当前草稿后重新校验白板、路径及文件对象身份；移动、删除、替换或切换白板后拒绝过期操作。
- 显式原生引用及 URI 不会被无关的文本兜底覆盖，跨仓库 URI 不会误配本库同名 PDF。

## 根因与验证

在 Obsidian 1.13.7 中使用真实 `dragManager.dragFile` 构造出的原生数据，是 extensionless `obsidian://open` URI 配合原生文件引用。旧版 1.0.24 将该事件送入实际白板舞台后，`defaultPrevented=false`，卡片数量仍为 0。新版同步接管事件并插入源文件引用。

本轮不修改笔记内容，不主动移动白板视角；拖入形成普通关联卡片，其后编辑和预览沿用既有能力。
