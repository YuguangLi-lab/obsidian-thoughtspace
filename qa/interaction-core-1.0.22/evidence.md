# 1.0.22 — 工作台、摘录导入、思维导图导出与 PDF 资源优化

本轮以完整备份的 **1.0.21 实际源码**为基线，保留已有未提交改动，没有用 Git HEAD 代替当前版本。逐文件核对归档后，确认修改 **8 个生产文件、7 个测试文件**，其中 **6 个测试文件新增 38 项运行用例**；没有新增生产依赖或改变白板数据格式。

**代码验证、演示环境原生验收、实际库安装及交付校验已完成。** 全仓 **2,640 / 2,640** 测试通过，无跳过或取消；TypeScript 与生产构建通过；ESLint **0 错误、79 项既有警告**；发布脚本测试 **7 / 7** 通过。演示环境已实际加载 **1.0.22**，21 项应用内检查通过（20 项工作流及 1 项关闭回调检查）。本报告仅包含合成输入、公开代码路径及汇总结果。

### 独立复审中发现并解决的回退

批量替换初稿在超过 8 项时建立全板索引，导致 1,200 对象白板的前 9 / 12 项替换读取全部 1,200 个 ID。最终改为仅收集所需 ID，收齐即停止，计数为 **9 / 12**；1 / 2 / 8 项仍为旧有 **1 / 3 / 36**。已经补入阈值与重复预览 ID 回归。本报告表格使用最终计数，不使用初稿回退数据。

搜索初稿先截取前缀再解析，拖慢尾部命中；最终改为单程逐行处理，作者同场对比未再观察到该退化。耗时仍受文本内容、宿主和机器影响。

## PDF 页资源生命周期与取舍

整本文档池复用时，旧版结束缩略图只释放文档租约，未向对应页请求清理。现在使用可选的 `PDFPageProxy.cleanup()`，并处理取消或超时之后才交付的页对象。页所有权先清空再执行释放，避免重入重复清理；cleanup 不存在或抛错不阻断画布及租约处理。

连续 30 页的**受控缓存模型**中，结束后保留的页缓存由 **30 份变为 0 份**，峰值由 **30 变为 1**，文档创建均为 1 次。这不是进程内存 MB，也不是实际图像资源字节测量。

独立审核使用 Obsidian 内实际 PDF.js **5.3.34** 解析合成 PDF，取得真实文档/页对象，并调用原生 cleanup、PDFObjects 与 operator-chunk 处理；渲染任务、DOM、时钟和页交付时序受控：

- **25 / 25** 个交错案例连续两轮通过，另有真实 document destroy 后迟到页的 **4 / 4** 个流程通过。
- 同页另一渲染任务尚未完成、或 operator list 最后一块尚未到达时，cleanup 延后生效；另一张卡片仍可完成。
- 22 个具备正常清理能力的案例中，真实 PDFObjects 标记由旧版保留变为新版释放；缺少 cleanup 或故意失败的案例仅验证兼容，不声称已释放资源。
- 取消、超时、迟到 resolve、反复 dispose 和 cleanup 抛错未产生迟到画布或未处理 Promise 拒绝。

这是**实际 PDF.js 契约与受控生产生命周期的联合验证**，不是实际 Canvas 光栅化、复杂 PDF 长时压力测试或前台体验验收。释放页资源后，返回已浏览页面可能需要 PDF.js 重新准备渲染数据；整本文档仍复用。该取舍减少持续浏览新页时的持有量，不能声称所有往返翻页都更快，也不能证明长期运行零泄漏。

## 差分与交叉复审

不同组的案例不汇总为“独立 bug 数”，也不把受控调用数当作原生 UI 验收数。

- **工作台独立复审**：12,000 个案例全等，含 3,585 个错误、7,790 个事务案例；覆盖编辑/失败后的输入状态、重复预览、锁定、合并拆分、引用重映射与导出。上述小选区回退已修复并再次通过同一差分。
- **编辑与搜索作者差分**：63,550 个输出/错误比较一致；相关 186 项测试通过。
- **编辑与搜索独立复审**：18,000 个选区、69,834 个重定位案例及 41,800 个搜索查询一致；重定位同时比较单次 wrapper 与批量 API，共 18,000 个混合批次，包含 56,738 次预期错误比较。同步导入位置与文件创建前后保护另经只读核对。
- **思维导图作者差分**：15,110 次完整结果/错误一致，包含 6,895 个成功和 8,215 个相同拒绝；相关 201 项测试通过。
- **思维导图独立复审**：以归档完整旧依赖、只替换目标模块的隔离旧依赖、当前完整实现三方比较，21,600 次结果一致；额外检查混合循环、导出边界及长 Unicode/XML 标题。
- **工作台界面独立复审**：80 组旧新界面/选区顺序比较和 3 组关闭回调边界通过；与思维导图相关套件合计 151 项通过。
- **PDF 作者差分**：1,600 组生产调用的输出、错误、画布和文档生命周期一致；新增页 cleanup 事件为预期差异，相关 63 项测试通过。独立原生 PDF.js 契约验证见上节。

随机差分和受控生命周期测试是有界证据，不保证所有第三方插件和未覆盖内容完全无兼容问题。
