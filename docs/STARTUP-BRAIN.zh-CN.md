# 脑图选中操作与长笔迹显示 · 1.3.36

本页说明 1.3.36 的低缩放脑图操作、引用导航与长笔迹显示。收集、命名阅读位置、来源引用位置、整簇整理和手写圈选继续可用，操作见[便利功能指南](CONVENIENCE.zh-CN.md)和[收集页指南](COLLECTION-WORKSPACE.zh-CN.md)。

## 脑图

点击或用 Tab 聚焦节点标题只选择节点，保持当前中心、阅读历史与已保存镜头。在画布之外的“选中节点操作”栏中使用“设为中心”才进入该节点的中心视图；“展开正文”“打开来源”“节点菜单”均在同一操作栏中；展开“新建关系”可选择上方父节点、下方子节点与左右关联。条目保持 44px，低缩放时不会叠在每个节点上；短窗口操作栏可以滚动。

引用位置导航条跟随当前脑图画布的可见范围，避开画布外的选中操作栏、缩放和分页控件。分屏、可见窗口变化、所属窗口内的容器滚动或重建画布时重新定位；极短空间通过导航条内部滚动保留 44px 操作，空间不足时暂时隐藏，窗口恢复后继续显示。

键盘可用 Tab 选择标题，Alt+向下进入选中节点操作栏；Shift+F10 打开该节点菜单。节点导航搜索仍可定位低缩放下难以点击的标题。节点标题仍随画布缩放，不声称每个缩小后的标题都保持 44px。

从非中心的选中节点创建关系，保存成功后才将来源设为中心并显示新关系。保存失败保留原中心与恢复信息以便重试；用户已换选、导航或关闭时，迟到的完成回调不能重新拉回旧位置。同窗切走再回到原标签也会永久取消旧请求，包括已经按下但尚未释放的操作；重新点击或按键会建立新的身份。原生正文与 IME 操作仍优先交由编辑器处理。

## 普通/手写白板的引用位置导航

引用位置导航条依据当前可见创作栏的实际左右边界留出横向空间，放在创作栏之外，保留两边各自的操作区域。创作栏显示、收起、换侧或重建时，导航条随可用范围重新定位；原有上下避让、导航条内部滚动与触控操作尺寸继续保留。短视口在同样边界下重新布局时保持内部滚动位置；导航条宽度始终按最终可用范围设置，保留换行按钮的可见与可操作区域。

## 手写白板

合法大笔迹板先完成全量源数据校验，再显示明确的“正在显示笔迹”状态。画布可移动、缩放，完整源笔迹可导出；新笔划和新圈选等待当前显示就绪，已经开始的草稿保持既有来源身份与 resize 保护。

显示只编码当前视野需要的精确压力片段，并分帧建立 SVG 节点。跨片段边界保留原始连接，仍为每笔一个 SVG path；完整适应画布时使用完整原始路径。源文件中的全部坐标、压力和点数不减精度、不截断。整笔命中、圈选、历史、保存、重开与 SVG 导出仍基于全量源数据。

规划缓存单独限制为 16 MiB，已有路径缓存 32 MiB 和历史 8 MiB 预算保持原样。正常 Markdown 路径可省掉一次转换；科学计数法、负的小数和巨大数字会保守保留原转换，以保持旧版的数字解释，不保证这些输入同样提速。

首个可用导航、可编辑就绪、当前可见显示完成与全笔迹适应显示完成是不同时间点；隐藏笔迹延后显示不能解释为总工作量提速。

## 搜索同步保护

来源 Markdown 仍存在、但宿主 metadata 暂未就绪时，搜索同步保留现有索引，等 metadata 更新事件后再同步。已确认的普通笔记转换或来源删除仍清理受管理的索引；暂时等待不修改原白板，也不自行循环重试。

## 验收边界

长笔迹检查使用两个独立样本，不能把点数相加或把两条路径当作同一负载：

- **65,520 点（8 × 8,190）**：接近单板 65,536 点上限。未抬笔的 17 点草稿可跨尺寸变化保留；释放时超过总预算，提交被拒绝并清除该草稿，原有采样和已保存源文件保留。被拒的新笔划不会自动另存为恢复草稿。
- **65,280 点（8 × 8,160）**：预留续写空间，用于持续输入、尺寸变化、提交／取消、导航隔离、已保存内容的新进程重开，以及受控保存失败后的恢复文件核对。它不证明 65,520 点样本能够继续追加同样负载。

具体结果与耗时见[1.3.36 验证说明](../qa/RELEASE-1.3.36.md)。新进程不等于清空系统磁盘缓存，宿主 metadata 可能预取；默认视野与全量显示、API 入口与原生入口分别记录。桌面自动化耗时包含控制、存储、渲染与等待开销，没有通用 FPS、延迟或设备性能达标结论。

桌面尺寸和 CDP 触控模拟不能替代实机验收。真实 iOS、Android、Pencil、WKWebView、系统键盘/IME、完整掌拒和设备性能均未测试。当前数据和剩余限制见[1.3.36 验证说明](../qa/RELEASE-1.3.36.md)。
