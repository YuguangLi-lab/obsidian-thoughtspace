# 界面与收集联动 · 1.3.36

1.3.36 统一普通白板、脑图、手写、收集、媒体、阅读、写作和设置的操作层级。正文和画布获得更多空间，常用操作保留直接入口，次要操作放入有名称的菜单。页面沿用 Obsidian 深浅主题和 ThoughtSpace 当前强调色、舒适／紧凑密度，不覆盖用户的卡片、纸张、背景或笔迹颜色。

## 常用操作

- 普通白板在手机和窄分屏保留「框选」「新建卡片」「工具」三个直接入口；连线、文本、插入和分组等完整操作可在「工具」中搜索。窄标题栏保留搜索和工作区，撤销、重做、收藏、常用视角及专注放在工作区菜单。底栏与工具面板避让所属窗口的宿主状态栏；点击「画布」展开吸附、间距和背景。格式栏用轻标签区分当前选区属性，完整操作可横向滚动。
- 脑图顶栏在窄容器保持单行，画布外的选中节点操作栏保留四向关系、正文和来源操作；低缩放时不会把同一组按钮重复叠在每个节点上。「最近浏览」按需展开；配色、背景、显示层级和设置仍在有名称的菜单中。
- 手写保留五个主要工具，显示当前工具、笔色与笔宽；颜色有名称与勾选。套索按整笔选择、移动、复制和删除。手指书写默认关闭，双指用于导航。菜单与 SVG 导出弹窗支持键盘返焦；详见[手写指南](HANDWRITING-IPAD.zh-CN.md)。
- 媒体、写作与阅读以正文为主。播放器、摘录、时间线和参考栏切换保留原输入；路径和失败说明可完整查看。媒体与在线摘录的 ⌘／Ctrl + Enter 只处理当前视图、当前输入和所属窗口。在线能力不足时仍可手动记录时间并在浏览器打开原链接。
- 材料侧栏、阅读桌和 PDF 引用在窄窗中保持操作可达；短 PDF 输入框保留内部滚动，可以编辑开头和结尾，再取消或确认。原生 PDF、笔记编辑器和播放器保留各自的内容归属。
- 新建白板先选择普通、脑图或手写类型，再填写名称；「文件格式」详情中可选择旧格式或 Markdown。创建成功后才记住偏好。
- 设置在窄容器把分类放在一行，可横向滚动；表单随自身容器换行。纸张和背景预览保留实际用户颜色，导入配置先校验后应用。保存外观偏好会更新已打开的收集、媒体等页面，保留正在编辑的草稿。

## 收集与白板

收集页保留正文优先的时间流。记录是普通 Markdown 笔记，可附原生标签、引用已有附件，并选择白板或分组投递。投递后记录仍留在时间流；记录下方可选择它在同一或多个白板中的具体卡片实例。

白板卡片菜单可以返回原收集记录，保留筛选、页码和当前会话的浏览位置；被筛选隐藏的记录会临时显露。侧栏与弹出窗口在发起窗口内导航，不接管另一窗口的输入。改名重新核对来源，删除、同路径替换、取消或新导航使旧操作失效。详见[收集页指南](COLLECTION-WORKSPACE.zh-CN.md)及[阅读与引用导航](CONVENIENCE.zh-CN.md)。

## 文件与恢复

已有保存、冲突、原生属性和多窗口所有权保护继续生效。收集输入有独立草稿检查点；旧快速收集窗口与其他内存草稿不因此获得同样的跨重启恢复能力。手写笔迹、相机与原生 Markdown 正文不因视觉更新而转换格式。

手写超过文档采样预算时会拒绝新提交，保留原笔迹与源文件，**被拒绝的未提交草稿会清空**；这与正常 resize 保留未抬笔草稿不同。保存失败时可只读对照磁盘、本地和已保存恢复版本；没有自动合并或覆盖。内存中的未保存内容在退出前仍需可靠保存或复制。
