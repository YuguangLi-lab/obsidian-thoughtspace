# 收集页：随手记录，再送往白板

本说明对应 **1.3.36**。收集页用于先记录正文，再整理到白板；此前白板里的「快速收集一条笔记」弹窗和命令继续保留。

## 开始记录

运行「ThoughtSpace: 打开收集」，或点击 ThoughtSpace 侧栏的「收集」。在上方直接写正文，点击「记录」或按 ⌘ / Ctrl + Enter。无需另填标题；普通 Enter 换行，输入法组合文字期间不触发保存。

「标签 · 附件 · 白板」展开后可设置原生标签、引用库内已有附件，以及选择已有普通或脑图白板、可用分组。附件选择只生成原生链接或嵌入，当前不提供从系统上传文件。也可以先只保存记录，以后再投递。

确认保存后输入区清空，仍停留在收集页。每一条都是卡片文件夹里的普通 Markdown 笔记，正文按输入保存。底部时间来自这条记录的创建时间，修改正文、改名或放入白板不会改变其时间流位置。

## 浏览和整理

- 「全部记录」保留已经送往白板的记录。
- 「未放入白板」按白板中的直接笔记卡片引用判断；片段、PDF 摘录等其他引用仍通过「定位引用」核对。白板索引不完整时明确显示未知，不把未知结果算作未投递。
- 标签可点击，层级标签可以按父标签筛选。搜索匹配标题、路径和标签，当前不提供全文搜索。
- 长记录可展开；每页最多 24 条，正文按可见位置读取；从白板返回被筛选隐藏的原记录时，可临时额外显示那一条。超长正文可打开原笔记完整阅读。
- 「更多」提供打开笔记、送往白板或分组、定位引用。重复投递到同一白板会跳过已有直接引用，不复制原笔记，也不自动移动已有卡片。
- 手机使用单列记录流和筛选抽屉。页面遵循 Obsidian 深浅主题与 ThoughtSpace 当前字体、强调色、舒适／紧凑密度和控件层级；保留正文优先、时间流和阅读留白。页面按当前容器和可见键盘区域调整布局。

「旧笔记收件箱」保留原入口。它仍按整库笔记是否被白板直接引用筛选，不等于新收集流。本次不扫描猜测旧快速收集记录、不回填旧笔记属性，也不改写它们的正文、文件名或标签。

## 与白板双向定位

记录下方显示已核实的白板位置；有多个引用时展开「所在白板」，再选择具体实例。同一笔记在同一白板上的多个卡片分别定位，多个白板也分别列出。更多位置仍可通过完整引用列表浏览。点击后复用既有引用导航及返回入口，原记录继续留在收集流。

在白板引用卡片的菜单选择「返回收集中的原记录」，可回到对应记录。当前筛选不被清空；被筛选隐藏的记录会临时展示并说明原因。「返回原浏览位置」恢复此前的浏览位置。这是当前收集页面会话内的状态，不承诺完整应用重启后恢复同一页码和滚动位置。新搜索、筛选、翻页、触摸或导航会取消旧 Markdown 预览的迟到位置恢复。原笔记与白板引用共享同一个 Markdown 文件，编辑不会生成一份收集副本。

笔记或白板改名、引用增删后会重新核对位置。索引未完成时保留未知提示；目标已删除、同路径被替换、收集标识冲突或引用已移除时拒绝过期跳转。侧栏依据实际活动页面处理，弹出窗口与主窗口分别路由。多窗口导航只在发起窗口内寻找收集页及目标白板；关闭页面、切换文件或发起新导航会取消迟到回调。

## 原生 Markdown 与标签

新记录仅增加 `thoughtspace_capture` 收集标识和 `thoughtspace_created` 创建时间；选择标签时使用原生 `tags` 属性。笔记正文仍可用 Obsidian 编辑。手动删除这些收集属性会使笔记退出收集流，原笔记不会因此删除。复制相同收集标识会触发恢复时的身份冲突检查。

筛选标签只读。若已启用 ThoughtSpace「自动按标签归档」，以后在原生笔记中修改标签仍遵循原有归档设置，可能移动文件；收集记录通过标识识别改名后的原笔记。

## 草稿与失败恢复

新收集页的输入保存在本库插件目录的 `collection-drafts/`，不同收集页各有独立会话。关闭页面后再打开可继续尚未完成的输入；正常应用重开也可恢复已写入的草稿。这个机制仅覆盖新收集页，不改变其他白板或旧快速收集弹窗的跨重启恢复能力。

写入前先核对临时文件，并保留上一份已确认的检查点。正式恢复文件缺失或损坏时，页面会显示可核对的上一份草稿并暂停自动提交，避免把旧检查点误当成“从未创建”而重复保存。失败材料会留在原会话目录供核对；这不等于对物理设备断电或文件系统故障作出保证。

开始保存后会固定本次身份和目标文件名。重复点击、创建完成却返回错误、取消后的迟到结果，都先核对这条记录，避免换名创建副本。无法证明结果时保留输入并显示待核对，不自动重建或覆盖原笔记。

创建笔记成功而白板投递失败时，会显示已保留的笔记位置。可重试原投递；没有尚待确认的白板写入时，也可以重新选目标或「仅保存记录」。应用重开后，尚未完成的目标需要重新选择，避免向已经替换的同名白板自动写入。

目标分组被锁定、移除或空间不足时会拒绝投递。手写白板不接收笔记卡片。白板有原生属性编辑、并发保存或磁盘版本冲突时，继续使用既有保护和恢复草稿；收集页不会自动覆盖冲突版本。
