# 收集页：随手记录，再送往白板

收集页用于先记录正文，再整理到白板；此前白板里的「快速收集一条笔记」弹窗和命令继续保留。

## 开始记录

运行「ThoughtSpace: 打开收集」，或点击 ThoughtSpace 侧栏的「收集」。在上方直接写正文，点击「记录」或按 ⌘ / Ctrl + Enter。无需另填标题；普通 Enter 换行，输入法组合文字期间不触发保存。

需要与当前笔记并排使用时，运行「ThoughtSpace: 在侧边栏打开收集」。默认在主窗口右侧停靠；再次运行会打开已有收集侧栏，不重复创建面板。原来的「打开收集」仍打开完整页面。独立弹出窗口没有可用侧栏时会提示回主窗口操作，不会替换当前笔记。

侧栏采用单列输入和记录流，搜索与筛选在「筛选」中展开。侧栏与完整页面共用记录，各自保留未提交的草稿；关闭后重新打开可继续已保存的草稿，不把另一收集页正在输入的内容抢过来。

「标签 · 附件 · 白板」展开后可设置原生标签、引用库内已有附件，以及选择已有普通或脑图白板、可用分组。附件选择只生成原生链接或嵌入，当前不提供从系统上传文件。也可以先只保存记录，以后再投递。

确认保存后输入区清空，仍停留在收集页。每一条都是卡片文件夹里的普通 Markdown 笔记，正文按输入保存。记录上方时间来自这条记录的创建时间，修改正文、改名或放入白板不会改变其时间流位置。

## 浏览和整理

- 默认收集流显示未归档记录，保留已经送往白板的记录；「已归档」可查看和恢复归档记录。
- 「未放入白板」按白板中的直接笔记卡片引用判断；片段、PDF 摘录等其他引用仍通过「定位引用」核对。白板索引不完整时明确显示未知，不把未知结果算作未投递。
- 标签可点击，层级标签可以按父标签筛选。搜索默认匹配标题、路径和标签；空格分隔的词必须同时匹配，`#项目` 包含该标签及子标签，`-#项目` 排除该标签及子标签。切换投递范围保留已有标签与搜索条件。
- 长记录可展开；每页最多 24 条，正文按可见位置读取；从白板返回被筛选隐藏的原记录时，可临时额外显示那一条。超长正文可打开原笔记完整阅读。
- 「更多」提供打开笔记、统一「送往…」与定位引用。「送往…」可选白板/分组、沉淀为笔记或查看投递回执。默认重复投递到同一白板跳过已有直接引用；明确勾选另建时才新增一个实例，不复制原笔记，也不自动移动已有卡片。
- 页面与整个插件统一使用原纸张配色，浅深色跟随 Obsidian，保留当前强调色和舒适／紧凑密度。标题、输入和记录以紧凑层级排列，次要工具按需展开；手机与窄侧栏采用单列记录流和筛选抽屉。页面按当前容器和可见键盘区域调整布局。

### 任务、原生引用与附件

组合筛选的「任务」提供全部、含任务、有未完成任务、全部完成和无任务。计数来自 Obsidian 原生任务索引，`x` / `X` 为已完成，其余自定义状态视为未完成；未知索引不参与具体任务筛选，代码块里的示例不计入。含任务的记录显示完成进度，任务内容仍在原生笔记中编辑。

每条记录可展开「引用与附件」，查看引用、被引用及库内附件。索引未知或链接尚未解析时明确提示；不猜测路径、不自动加载外部内容。每组最多显示 100 项，完整内容在原笔记查看。附件入口支持文件名/路径/来源搜索、类型筛选及每页 24 项；可打开附件，或回到来源记录。索引变化后先刷新，过期文件句柄无法继续跳转。原生文件页工具栏的「返回收集来源记录」保留原筛选，必要时临时展示来源。

### 逐条整理与沉淀

展开「整理」后，选择「逐条整理当前结果」。本轮固定开始时的记录及顺序，最多 500 条；过程中新增记录不会插入队列。上一条、下一条和稍后处理只移动游标，退出保留输入草稿和原浏览位置。焦点在整理区域或记录本身时可用左右方向键切换、Escape 退出；文本输入和已有控件的按键不被接管。来源改名、删除或标识冲突会使过期操作失效。

「送往… → 沉淀为笔记…」提供新建 Markdown 或追加到已有笔记。新建路径需在已有文件夹内，遇到同名文件拒绝覆盖。追加可选择原生标题下的末尾，或整个笔记末尾；同名标题按位置区分。预览显示目标与实际将写入的 Markdown，修改目标后必须重新预览。来源与内部引用转换为含扩展名的完整库内路径，保留附件别名、嵌入和小节定位，避免新目标同名后短链误指向自己。无法准确解析的链接拒绝写入；本地引用式链接需先在原文改为直接链接。来源和原关系始终保留，成功不自动归档。

写入前保存独立操作意图；重复确认不会再写一次。若保存接口报错，会先读回核对，分别显示已确认、已存在、未写入或待核对。关闭/新导航取消尚未开始的写入，已开始的操作仍保存实际回执。未知结果锁住同来源的新操作，最近记录只供只读核对，不自动重新执行或解除锁定；请保留 `collection-library/note-exports/` 正式日志及恢复材料，再核对目标原文。重新打开能恢复核对入口，不保证跨重启继续当前整理游标。

### 投递回执与明确另建

选择白板后默认确认已有引用，不会重复添加；已知位置提供直接定位入口。需要同一来源在同一白板再出现一张卡片时，明确勾选「另建一张卡片」，再确认。首次确认固定目标分组和另建选择，失败重试沿用同一次意图。已有引用的结果也可重新选择目标并明确另建，形成新意图；批量投递始终跳过已有引用。

回执保存来源标识/创建时间、白板标识、卡片标识和确认状态，位于 `collection-library/board-deliveries/`。来源与目标不会仅按正文相同合并。白板缺少稳定标识时，只在明确投递事务中补充；冲突检查覆盖已加载会话及已选择目标。未知的旧投递会阻止新意图，只有精确读回目标标识与卡片才能确认，不因重开自动新增。旧引用仍通过原来的所在白板和定位引用入口查看。

### 每天新增记录热力图

输入区下方的「记录热力图」默认收起。展开后按设备本地日历日显示新增收集数量；宽桌面可看全年，窄屏显示可触控的月历；容器不足 320px 时改为带星期标记的顺序日期网格，保留至少 44px 点击区域。沿用当前深浅主题与强调色，日期提示精确数量，今天和选择日期有独立标记。年份可选择当前年或有记录的年份。

统计全部具有有效收集标识及创建时间的记录，**包含归档，不受当前搜索、标签、置顶、投递范围或日期筛选影响**。依据 `thoughtspace_created`，不使用文件修改时间；编辑、置顶、投递和归档不会新增一条计数，归档／恢复只改变当日归档子计数。缺失或无效收集时间的旧笔记不推测、不补写；明确从原生属性更改有效创建时间后，计数随元数据重新归属日期。

点击某日将开始／结束日期都设为该日，并保留其他筛选条件，因此下面列表可能少于热力图总数。例如某日共 5 条、其中 2 条已归档，默认收集流最多显示另外 3 条；标签或关键词还能进一步缩小结果。可用「清除日期」只撤销日期条件，其余条件保持。若当前包含正文，点击日期或清除日期只准备条件，仍需手动「开始搜索」，不会因查看热力图启动全文扫描。日期条件可按原有方式保存为常用筛选。

热力图仅汇总已有元数据，不读取记录正文、不写入笔记或建立正文缓存。可通过 Tab 进入日期格，使用方向键移动，Enter／空格选择；窄屏提供上一月／下一月及今天入口。热力图刷新不重建输入区，不修改草稿或选区。

### 查找正文与组合条件

开启「包含正文」后，有普通关键词的查询才会按需读取收集笔记。标题、路径、标签和正文可共同满足多个词；结果显示独立的纯文本命中片段，原生 Markdown 正文不被改写。仅搜索 `#标签`、空查询或未开启正文时，不扫描所有记录的正文。

高级筛选可组合开始／结束日期、投递范围和仅置顶。日期按本机本地日历日计算，包含起止两天，依据原创建时间，不依据修改时间。记录未知的白板索引状态不能被算作「未放入白板」。

所有收集页的全文扫描共享最多两条笔记的读取额度，不保留全库正文缓存；可见正文预览使用独立的有界读取队列。超过 2 MiB、读取失败或身份无法核实的记录会计入未完整读取数量；部分结果不代表这些记录都没有命中。扫描可取消或重试，新查询、改名、修改、删除、关闭页面和新导航使旧结果失效。搜索内容不会写入笔记；输入法组合文字完成后才开始查询。搜索正在进行时，上方未保存的记录草稿保持独立。

### 保存常用筛选

筛选栏中的「已保存的筛选」可将当前条件命名保存，最多 20 组，每个名称最多 80 个字符。同名保存会拒绝覆盖；不再需要时可以明确删除，原记录不受影响。

应用普通筛选后立即检索元数据。含正文的已保存筛选只填入条件；点击「开始搜索」或在搜索框按非输入法组合中的 Enter 后才扫描正文。其后修改任一条件会重新等待手动开始。保存、应用、删除筛选不会修改笔记或保留正文、搜索结果、目标白板权限。

筛选文件位于插件目录 `collection-library/saved-filters.json`。多个收集页共享同一组筛选；如果文件被外部改动、损坏或保存结果无法核实，会保留最后确认的条件供查看，并停止继续覆盖。应先备份并核对正式文件及相邻恢复材料。

### 选择本页记录并批量整理

查询完整结束、结果没有过期时，展开「整理」，点击「选择当前页记录」，逐条勾选或「全选本页」。每批最多 24 条，只包括当前页内明确选择的记录，不包括其他页或临时定位显示的隐藏记录。读取不完整的正文搜索不能用于批量选择。

可「送往白板…」「归档…」或「恢复…」。确认区显示记录标题和原路径；投递还要核对目标白板和分组。确认后清单冻结，逐条保存，不因自己的索引更新而更换待处理记录。重复投递只确认目标白板已有引用，不移动已有卡片到所选分组。归档或恢复只修改对应原生布尔属性，不移动笔记、不改标签、不移除白板引用。

改变筛选、翻页或导航会清除未确认的选择。执行中点击「停止后续」或离开页面，尚未开始的记录不再执行；已经开始的保存仍核对实际回执，不承诺撤回。遇到第一条失败或结果不明也会停止，报告逐项区分已确认、已有引用／状态已符合、未写入、结果待核对和未开始。不会把部分完成说成全部完成。

批次日志位于 `collection-library/batches/`，每批独立保存。最近 20 批的报告可展开核对；重开应用后仍为只读，不会自动继续或重试，不保存可继续写入的白板令牌。结果待核对时先查看原笔记、原目标及白板恢复草稿，再明确选择需要处理的记录。日志损坏或缺失时尝试只读显示已确认备份，原文件和材料保留。这是逻辑读回确认，不是物理断电保证。

### 置顶、归档和恢复

记录的「更多」提供置顶／取消置顶、归档／恢复。置顶记录在当前筛选内排到前面，其余顺序仍按原创建时间；归档只退出默认收集流，不移动文件、不删除正文或附件、不移除白板卡片。投递成功不会自动归档。已归档记录仍可通过「已归档」检索、打开或恢复，从白板返回时也可临时展示。

这两项状态分别使用原生布尔属性 `thoughtspace_pinned` 和 `thoughtspace_archived`，未设置视为 false。只有明确操作该条记录时才修改对应属性；不会扫描回填旧笔记。可以在 Obsidian 原生属性中查看或修改，非布尔值需要先在原生笔记中核对。恢复归档写入 false，不改变创建时间或原有收集标识。宿主原生属性接口可能调整 YAML 排版，正文及其他属性语义保持原样。

整理操作会核对原笔记身份、状态是否被另一窗口改动，以及原生编辑是否已同步。无法确认写入结果时会提示核对，不自动重复写入。取消发生在磁盘提交前会停止操作；提交完成后的导航不会回滚已经确认的状态。原生笔记编辑仍通过「打开笔记」进行，本候选没有新增一套页内全文编辑器。

「旧笔记收件箱」保留原入口。它仍按整库笔记是否被白板直接引用筛选，不等于新收集流。本次不扫描猜测旧快速收集记录、不回填旧笔记属性，也不改写它们的正文、文件名或标签。

## 与白板双向定位

记录下方显示已核实的白板位置；有多个引用时展开「所在白板」，再选择具体实例。同一笔记在同一白板上的多个卡片分别定位，多个白板也分别列出。更多位置仍可通过完整引用列表浏览。点击后复用既有引用导航及返回入口，原记录继续留在收集流。

在白板引用卡片的菜单选择「返回收集中的原记录」，可回到对应记录。当前筛选不被清空；被筛选隐藏的记录会临时展示并说明原因。「返回原浏览位置」恢复此前的浏览位置。这是当前收集页面会话内的状态，不承诺完整应用重启后恢复同一页码和滚动位置。新搜索、筛选、翻页、触摸或导航会取消旧 Markdown 预览的迟到位置恢复。原笔记与白板引用共享同一个 Markdown 文件，编辑不会生成一份收集副本。

笔记或白板改名、引用增删后会重新核对位置。索引未完成时保留未知提示；目标已删除、同路径被替换、收集标识冲突或引用已移除时拒绝过期跳转。侧栏依据实际活动页面处理，弹出窗口与主窗口分别路由。多窗口导航只在发起窗口内寻找收集页及目标白板；关闭页面、切换文件或发起新导航会取消迟到回调。

## 原生 Markdown 与标签

新记录仅增加 `thoughtspace_capture` 收集标识和 `thoughtspace_created` 创建时间；选择标签时使用原生 `tags` 属性。笔记正文仍可用 Obsidian 编辑。手动删除这些收集属性会使笔记退出收集流，原笔记不会因此删除。复制相同收集标识会触发恢复时的身份冲突检查。

筛选标签只读。若已启用 ThoughtSpace「自动按标签归档」，以后在原生笔记中修改标签仍遵循原有归档设置，可能移动文件；收集记录通过标识识别改名后的原笔记。

## 草稿与失败恢复

新收集页的输入保存在本库插件目录的 `collection-drafts/`，不同收集页各有独立会话。关闭页面后再打开可继续尚未完成的输入；正常应用重开也可恢复已写入的草稿。这个机制仅覆盖新收集页，不改变其他白板或旧快速收集弹窗的跨重启恢复能力。

写入前先核对临时文件，并保留上一份已确认的检查点。正式恢复文件缺失或损坏时，页面会显示可核对的上一份草稿并暂停自动提交，避免把旧检查点误当成“从未创建”而重复保存。失败材料会留在原会话目录供核对；这不等于对物理设备断电或文件系统故障作出保证。

开始保存后会固定本次身份和目标文件名。重复点击、创建完成却返回错误、取消后的迟到结果，都先核对这条记录，避免换名创建副本。无法证明结果时保留输入并显示待核对，不自动重建或覆盖原笔记。

创建笔记成功而白板投递失败时，会显示已保留的笔记位置。可重试原投递；没有尚待确认的白板写入时，也可以重新选目标或「仅保存记录」。应用重开后，尚未完成的目标需要重新选择，避免向已经替换的同名白板自动写入。

目标分组被锁定、移除或空间不足时会拒绝投递。手写白板不接收笔记卡片。白板有原生属性编辑、并发保存或磁盘版本冲突时，继续使用既有保护和恢复草稿；收集页不会自动覆盖冲突版本。

## 验证范围

功能候选验收使用自制库、独立 Obsidian 配置和独立进程，核对实际截图、故障注入结果和新进程重启。手机、平板、可见键盘区域和触控布局使用桌面 Chromium 模拟；没有验证物理 iOS、Android、Pencil、WKWebView、系统移动输入法、真实软键盘或移动设备性能。无 Node 探针仅到模块执行与插件构造函数，不包含 `onload`、移动 UI 或存储。本候选的新增验收结果见随包提供的本地候选验证记录；[1.3.36 验证摘要](../qa/RELEASE-1.3.36.md)仅记录稳定基线，不代表新增功能已经通过。

## 收集背景

收集默认使用暖白纸张。点击标题旁的调色盘，可选择点阵、网格、纯色、纸张纹理或本地背景图片；“自定义纸张…”可调整纸色和纹理强度。设置独立保存，完整页与右侧栏同步，不改变白板背景。可用“恢复暖白纸张”回到默认。图片沿用白板的本地导入与格式校验，文字区保留可读性底纸。
