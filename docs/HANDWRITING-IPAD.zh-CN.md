# 手写白板 · 1.3.36

新增「更多 → 导出 PNG…」可保存透明或暖白背景的视觉附件，保留原笔迹；尺寸和保存边界见[导出与恢复指南](REVIEW-SOURCES-RECOVERY.zh-CN.md#手写-png-导出)。

独立手写白板支持桌面鼠标和 Pointer Events 笔输入，并提供手机／平板容器布局。**验收采用隔离桌面原生交互、pen／touch 与尺寸模拟；真实 iOS、Android、Apple Pencil、WKWebView、系统移动输入法和真实软键盘未测。** 模拟通过不代表实机验证。候选证据及正式发行复核状态见[1.3.36 验证摘要](../qa/RELEASE-1.3.36.md)。

## 新建与使用

在 ThoughtSpace 的“新建白板或脑图…”中选 **手写白板**，再选 `.thoughtspace` 或 Markdown `.md`。成功创建并打开后记住类型和格式；取消或失败不改变偏好。普通白板、脑图以及原有文件不会转换为手写板。

- **笔**：Pencil/笔输入写画；鼠标左键也可写画。读取可用的压力，否则使用固定可见宽度；无需 OCR 或网络。
- **整笔擦除**：触及一条笔迹会擦除整条笔迹；不是局部像素橡皮。抬笔才提交，撤销可恢复。
- **移动**：移动工具用鼠标拖动画布；默认触摸用双指移动与缩放，单指不会写画。书写期间的手指不会改变镜头，已按住的触摸必须抬起后重新开始导航。
- **手指书写**：显式打开工具栏的开关后，单指可写画或整笔擦除；第二指会取消尚未提交的手指草稿并进入双指导航。笔可以接管手指输入。这是当前视图的选择，重新打开默认关闭，避免误触笔迹。
- 颜色与粗细作用于下一笔。**撤销 / 重做**按完整笔划操作；键盘支持 Cmd/Ctrl+Z、Shift+Cmd/Ctrl+Z 和 Ctrl/Cmd+Y。
- **居中笔迹**适应笔迹范围。每次重新打开默认为笔工具；世界坐标在移动和缩放后保持稳定。
- **套索**按整笔选择；拖动选区移动，邻近的「复制」「删除」「取消」处理当前选区。移动、复制和删除各为一次可撤销操作，不将一笔裁成碎片。第二个接触点、失焦、取消或新的导航会使旧预览失效。

未抬笔的草稿不写入文件。旋转、分屏、画布尺寸或 visualViewport 变化会重绘草稿，保留已经采样的世界坐标与镜头；临时零尺寸不接收新采样。Escape、取消事件、意外失去捕获、切换工具、失焦或离开白板仍取消当前草稿；已经提交的笔迹保留。开始原生 Properties/Markdown 交接时也要先抬笔。手写页保留原生文件标题、保存反馈和 Properties 入口；原生页或其他窗口的写入保护不会被绕过。

## SVG 导出与版本对照

从更多操作打开 SVG 导出，选择已有的原生 Markdown 笔记。导出将完整笔迹保存为 SVG 附件，在所选笔记中插入引用并保留来源白板回链；附件与笔记追加分别核对，失败时保留具体状态供重试，不能因重复点击重复追加。导出等待期间若来源、目标或导航发生变化，需要重新核对。

SVG 是便于阅读和引用的视觉副本，**不是可导回为可编辑笔迹的白板格式**。继续编辑请保留原 `.thoughtspace` 或 Markdown 白板。原生 Canvas 无法表示笔迹，相关有损导出仍会拒绝。

保存反馈中的「对照白板版本」可只读查看磁盘当前版、当前本地版和可核实的恢复草稿，比较笔迹、卡片、布局及属性／正文差异。打开前会再次核对版本；变化时先刷新，无法读取不当作空白。这里不自动合并或覆盖原文件。当前本地版本尚未可靠落盘时仍只在当前窗口中保留，请复制或完成保存后再关闭。

## 数据与边界

笔迹随原白板保存，另存、复制、恢复草稿和历史使用同一份白板数据。新手写类型需要 1.3.36 或兼容的手写预发布版本；1.3.35 及更早版本不能打开它。保留完整副本，降级时不要用旧版编辑手写文件。保存失败时打开恢复副本；原存储和恢复存储都失败时，点击“复制未保存白板”，把只读框中的完整内容复制到独立文件，保持原 `.md` 或 `.thoughtspace` 格式。副本包含笔迹、视角及原生属性/正文，不解除原文件写保护。剪贴板被拒绝时可“选择全部”手动复制。内存草稿不能跨进程保留，关闭应用前必须可靠保存副本。

单笔最多 8192 个采样，单板最多 65536 个采样、2000 条笔迹。达到单笔上限会明确取消这一整笔并提示未保存；请抬笔再画或分成多笔。文档总预算超限会拒绝提交并保留原笔迹及源文件，**被拒的未提交草稿会清空**。正常 resize 保留草稿不意味着超限拒绝后还能恢复该笔；请抬笔后调整内容，再开始新的书写。没有静默截断或有损修改保存采样；显示路径以 0.001 世界单位精度生成。大笔迹先校验完整源数据，再按视野分帧显示；等待显示时可移动、缩放和导出，新书写／套索等待可编辑就绪。显示规划缓存限制为 16 MiB，路径缓存和历史保留各自预算。完整源采样、整笔操作、历史与 SVG 导出不减精度；可导航、可编辑、可见部分与全部显示完成是不同阶段，不承诺实际 iPad 延迟或通用大型文档提速。

原生 Canvas 不能表示此笔迹，转换含笔迹的白板会被拒绝；SVG 导出则保留视觉内容。请保留原文件或另存完整白板副本。手写页暂不显示卡片与连线；外部手动组合的文件会提示有这些内容，并保留其数据。

移动端不支持电脑外部路径、桌面本地文件后端和 Electron 在线播放器。仓库本地媒体与原有引用保持原数据。没有通用掌拒、Pencil 双击、悬停、PencilKit 或原生系统手势保证；USB-C Pencil 等不提供压力的硬件仍使用宽度回退。[Pointer Events 规范](https://www.w3.org/TR/pointerevents3/)、[WebKit Safari 18.2 合并采样支持](https://webkit.org/blog/16301/webkit-features-in-safari-18-2/)和[Apple Pencil 对比](https://www.apple.com/apple-pencil/)是输入边界的依据。

## 有设备时的可选 iPad 实机验证

以下步骤供后续获得设备时补充验证。当前尚未完成这些物理设备检查，无 Node 探针也只到模块执行与构造函数，没有运行 `onload`、真实移动 UI 或存储。

仅在新建的专用测试仓库中手动安装对应版本的三个运行文件；不要覆盖真实笔记、设置或现有 `data.json`。记录 Obsidian、iPadOS、iPad 和 Pencil 型号。

1. 从新建入口分别创建两种格式的手写板。用 Pencil 写字、点画、长线，比较轻重压力；无压力型号确认回退可见。
2. 默认单指不写画；打开“手指书写”后验证单指写画、双指接管、第三指与笔输入，确认抬笔后的旧触摸不会使镜头跳动，画布无误建文本框/卡片/连线。
3. 移动、缩放后再写；整笔擦除、撤销、重做；连续快速笔划、快速换工具、取消和失焦；旋转屏幕及分屏调整时确认当前草稿和镜头保留，取消事件仍丢弃未提交草稿。
4. 等保存反馈完成，关闭并重开，再完全重启 Obsidian；两种格式逐一确认身份、笔迹坐标、颜色、宽度、默认笔工具和另存副本。
5. 打开原生 Markdown / Properties，改属性并返回白板；双页或多窗口同时打开，确认仍有原生所有者时手写只读，最新原生内容不被覆盖。未知原生保存能力必须保持保护，不能以模拟通过替代实机结果。
6. 在专用测试环境制造可恢复保存故障，确认显示恢复/重试入口、原文件保留；重试完成后重开。测试超过采样预算时能理解未保存提示且下一笔恢复。
7. 浅色、深色及第三方主题检查笔迹、选中/焦点、按钮点击范围；记录长笔输入、提交和重开的阶段耗时与尾部卡顿，附真实屏幕截图。

有实机证据后再更新验证范围；目前仍标注 iPad／Pencil 实机未测。操作层级和性能边界另见[界面指南](UI-REFINEMENT.zh-CN.md)与[长笔迹显示说明](STARTUP-BRAIN.zh-CN.md)。
