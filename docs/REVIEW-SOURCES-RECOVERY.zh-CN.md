# 回顾、重复提醒、来源检查与恢复

这些入口沿用纸质界面，原有记录、笔迹和白板格式兼容。它们不自动整理或删除内容。

## 今日回顾

收集记录的「更多 → 安排回顾」可选择日期，或安排到 1、3、7 天后。「组合筛选 → 今日回顾（含逾期）」显示本地日历今天及更早到期的未归档记录；可叠加搜索、标签和其他条件，也可保存此筛选。

只有明确安排时，才会通过 Obsidian 原生 Properties 写入 `thoughtspace_review_version: 1` 和 `thoughtspace_review_on: YYYY-MM-DD`。取消只移除这两个字段，不回填旧笔记，不接管其他插件的 `due` 等字段。未知版本或不完整字段提示核对，不能直接覆盖。另一窗口修改日期、笔记身份变化或结果不确定时，先刷新并打开原笔记核对。

## 完全重复的收集提醒

点击「记录」前，只读检查现有收集正文。完全相同的文本、或整段只有一个相同 HTTP(S) URL 时提示已有记录；URL 两端空白忽略，路径、查询参数、片段和大小写不归一化。含附件时检查实际将保存的正文及附件链接。不模糊匹配，不合并、覆盖、删除或自动归档。

可打开已有记录、取消并保留草稿，或明确「仍然保存新记录」。改变草稿或导航后旧确认失效。读取失败或过大的记录明确显示未检查，不将结果称为完整去重，仍可明确保存。最多同时读取两条记录，不建立持续正文缓存。

## 静态写作引用的来源检查

写作选项中的「检查静态引用来源」比较新编排的原笔记/文本材料，以及新插入静态摘录时记录的来源基线。显示引用时的原文和来源原区间的现内容，只供核对，不自动替换文章。位置移动后需要回到原材料重新选段。

基线随白板写作数据保存，包含路径、创建时间、原区间、摘要哈希、有限预览及所插入文本。每篇最多 500 条，总预览和所插入文本有大小上限，单个预览最多 2,000 字符。旧稿没有基线时不猜测版本；空材料不建立虚假的文字基线。原生动态嵌入仍由 Obsidian 更新。

这里只比较已落盘内容；来源存在未保存编辑时提示先处理原笔记。路径丢失、身份/创建时间变化、来源过大或读取期间变化时拒绝猜测。正文改写或移除原引用后，记录显示已脱离原引用。

## 手写 PNG 导出

手写白板「更多 → 导出 PNG…」可选暖白纸张或透明背景。使用原笔迹生成独立视觉附件，保留原笔迹和 SVG 导出入口。

按比例缩放，单边最多 4,096 像素、总量最多 800 万像素、编码文件最多 32 MiB；图形范围以现有 SVG 导出为准。使用 Obsidian 附件位置和可用文件名，重名不覆盖。取消尚未开始的写入不创建附件。创建结果不确定时保留文件并提示核对，不自动再创建；写后校验失败不冒称成功。

## 统一恢复中心

运行「ThoughtSpace: 打开恢复中心」，或从收集导航/写作选项进入。集中列出已有收集会话、写作、受阻白板、媒体及在线视频草稿，区分：

- **已确认落盘检查点**：通过现有存储流程读取并校验的副本，可能比当前输入旧；不代表物理断电或跨设备恢复保证。
- **易失会话内存**：当前可见输入或本次进程保留副本，退出、重启可能丢失。
- **状态待核对**：损坏、暂不可读或回退材料，不作恢复保证。

展开可只读查看、复制当前全文，或打开原模块的受控处理入口。复制只含文字，媒体截图须在原恢复入口处理。剪贴板不可用时可手动选择全文。中心不自动回写、合并、清理、重放事务或解除保存保护；原模块身份与并发检查继续生效。列表有数量及预览大小上限，超出时回原模块核对。
