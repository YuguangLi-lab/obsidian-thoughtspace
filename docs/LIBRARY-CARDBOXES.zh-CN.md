# 资料库鸟瞰与卡片盒

通过原有「卡片资料库」入口打开。默认「鸟瞰」显示资料卡片，原有「资料表」「进度看板」继续保留各自的筛选和操作。

## 查找资料

默认只显示卡片盒、搜索框和资料卡片。「筛选与排序」按需展开，可组合资料范围、目录（可含子目录）、多标签和原生 Properties。不同条件同时满足；多个标签可选择「同时满足」或「满足任一」。数值 `0`、布尔 `false` 和同名字符串分别匹配，不作为「未填写」。数组属性按其中任一值匹配。

标签与属性选项的数量基于当前资料范围、目录和已有卡片盒规则，尚未应用临时标签或属性条件。已选的零数量选项仍可移除。尚未完成 Obsidian 属性索引的笔记会明确提示，暂不计入结果。

搜索默认检查标题、路径和标签。启用「包含笔记正文」后才读取正文；Properties 区域不作为正文搜索。多个搜索词同时满足，可分布在元数据与正文中。命中片段以纯文本高亮显示；收起筛选面板后，点击片段可打开原笔记并定位到相应行，点击标题则按需预览。原文已经变化、编辑器内容不一致或导航已取消时，不跳到旧位置，也不覆盖原笔记。

每次先显示 12 篇，最多累计 48 篇后翻页。单篇正文限 2 MB，每轮保留正文预算 20 MB；变化、读取失败及超限会提示「部分结果」，不能把该结果当成完整全文索引。PDF 和其他二进制附件不参与此次 Markdown 正文搜索。快速输入、切换视图或关闭窗口会使旧搜索失效。

## 保存卡片盒

在左侧「卡片盒」旁点击加号，或在筛选面板选择「保存当前筛选为卡片盒」。卡片盒只保存动态规则，不复制或移动文件，也不修改笔记属性。原笔记、标签或 Properties 变化后，成员重新计算。

打开卡片盒后，临时筛选继续与盒内规则相交；「清除临时筛选」不会清除盒内规则。此时另存卡片盒会包含两者。需要重新从全库筛选时，选择「全部资料」。绑定当前白板的规则只对原白板有效，不会因换到其他白板而扩大为全库。正文卡片盒的导航计数显示省略号，打开并搜索后才显示匹配数量。

最多保存 50 个卡片盒。管理入口支持重命名和二次确认移除，移除不删除原笔记。同一插件实例中的多个资料库窗口共享配置；并发保存会检查配置版本，过期窗口不会覆盖新规则。落盘失败时保留名称输入并显示错误，可重试或取消。

## 外观与数据

使用插件已有的强调色、密度与宿主浅深色，默认延续暖白纸质。白板纸色/纹理和收集背景仍保持原有独立范围，不会被资料库改写。窄窗将卡片盒收为可关闭抽屉；筛选面板和抽屉均可使用 Escape 返回。

规则保存在插件设置的 `database.library` 中，旧配置缺少该字段时按空集合处理。此次没有自动合并、移动、删除资料或回填旧笔记属性；也没有手动加入/排除功能。
