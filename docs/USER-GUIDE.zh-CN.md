# ThoughtSpace Whiteboard 用户教程

简体中文 · [English](USER-GUIDE.md) · [项目首页](../README.zh-CN.md) · [Markdown 白板详解](markdown-boards.zh-CN.md)

适用于 **ThoughtSpace Whiteboard 1.3.35** 与桌面版 Obsidian **1.13.7 或更新版本**。设置页可选中文或英文，其他菜单和工作区目前主要使用中文。

本教程用一个“**城市降温研究**”练习串起完整流程：提出问题，放入笔记、PDF 和图片，在脑图中组织关系，回到原生属性，再把视频摘录与证据编排成 Markdown 草稿。示例名称可换成你的课题；使用你自己的练习材料，不需要额外账号或演示视频。

## 1. 安装与更新

### 首次安装

1. 在 Obsidian **设置 → 第三方插件** 搜索 **ThoughtSpace Whiteboard**。若当前社区目录提供该插件，安装并启用，然后跳到第 4 步；搜索不到时使用手动安装。
2. 手动安装：打开 [GitHub Releases](https://github.com/YuguangLi-lab/obsidian-thoughtspace/releases)，进入所需版本，下载同一版本的 **`main.js`、`manifest.json`、`styles.css`**。
3. 在练习库的 `.obsidian/plugins/thoughtspace/` 中直接放入三个文件。不要多嵌套一层文件夹，也不要把 GitHub 自动生成的源码压缩包当安装包。
4. 重新加载 Obsidian，在第三方插件列表启用插件。打开命令面板，搜索 **新建白板或脑图…**。

默认配置目录是 `.obsidian`；使用自定义配置目录时，放到对应的 `plugins/thoughtspace/`。插件目前不支持移动端。

Release 还提供 `thoughtspace-版本号.zip` 安装 ZIP 和 `SHA256SUMS.txt`。ZIP 是手动下载辅助包；解压后，Obsidian 仍只安装上述三个运行文件。需要核验下载时，在本机计算所下载文件的 SHA-256，与**同一 Release** 的 `SHA256SUMS.txt` 对应项逐项比较。例如 macOS/Linux 可运行 `shasum -a 256 thoughtspace-1.3.35.zip`，Windows PowerShell 可运行 `Get-FileHash thoughtspace-1.3.35.zip -Algorithm SHA256`。文件名按实际版本替换；这一校验需要你手动执行，Obsidian 不会自动验证 ZIP 或校验清单。

### 更新已有安装

1. 保存笔记正文和媒体摘录，确认白板保存完成；普通白板显示 **已保存**，脑图不应还有待保存或错误提示。有只读或冲突提示时先按 [FAQ](#troubleshooting) 保留内容。
2. 备份仓库及配置目录，包含 `.md`、`.thoughtspace`、附件和插件数据。
3. 暂时关闭插件，用同一 Release 的三个运行文件替换旧文件。
4. **保留 `data.json`、背景图片、布局快照和其他已有数据文件**，不要删除整个插件目录。
5. 重新启用，检查版本，重开一张白板和一篇关联笔记。

社区目录与 GitHub Release 的版本可能不同步，以各自实际显示的版本为准。升级不会自动迁移旧白板。

## 2. 从“城市降温研究”到一份草稿

### 第一步：新建研究白板

1. 侧栏点 **新建 → 新建白板或脑图…**，或在命令面板运行同名命令。
2. **白板类型** 选 **普通白板**，**文件格式** 选 **Markdown (.md)**，名称填“城市降温研究”，点 **创建**。
3. 双击空白处，写“街道树荫如何影响行人感受到的热？”，保存这段白板文本。

通用新建初次默认普通旧格式白板，成功创建并打开后记住本库的类型和格式。旧格式仍可用；需要原生 Properties 时选 Markdown。四个明确格式的创建命令与独立另存入口见 [格式选择](markdown-boards.zh-CN.md#创建与打开)。

### 第二步：放入自己的材料

1. 在 Obsidian 建一篇练习笔记“树荫观察”，记录时段、位置和待核实问题，然后从文件列表拖到白板。
2. 拖入一份可选择文字的研究 PDF；点 **插入内容 → 图片**，选择一张街道照片。三者都是引用，原文件留在原位。
3. 笔记卡片右键 **右侧打开笔记**；PDF 卡片右键 **右侧阅读 PDF**。选中文字拖到空白处，生成有来源的摘录。

扫描 PDF 没有文本层时需另行 OCR。更多导入、PDF++ 引用和追加证据的用法见 [材料导入](#media-import)。

![普通白板：把问题、来源笔记与文章结构放在一起](https://raw.githubusercontent.com/YuguangLi-lab/obsidian-thoughtspace/main/docs/images/whiteboard-research.png)

1.3.35 真实界面，摄于专用自制练习库；用于说明操作，不代表研究结论。

### 第三步：把证据连起来

1. 从问题文本边缘的连接点拖到“树荫观察”卡片，创建关系。
2. 双击连线说明，写“提供观察”；另一条线可写“需要核实”。
3. 按住 Shift 在空白处拖动框选材料，用 **分组框** 命名“待阅读”。

普通连线不自动成为父子分支；需要逐层折叠时，右键连线选择 **允许折叠（设为父子分支）**。详见 [关系与折叠](#connections)。

### 第四步：在脑图中展开问题

1. 再运行 **新建白板或脑图…**，类型选 **脑图白板**、格式选 **Markdown (.md)**，命名“城市降温问题树”。
2. 空白脑图点 **添加知识节点**，来源选 **先记想法**，输入“城市降温”，确认。第一个节点成为中心。
3. 中心下方加号添加子节点“树荫”，上方添加父节点“城市环境”；左、右加号添加双向关联，例如“步行体验”。
4. 点节点可切换中心，用 **脑图菜单 → 显示 1–5 层** 调整阅读范围；节点的展开按钮查看内容。
5. 想法节点菜单选 **整理成笔记**：要生成文件选 **新建笔记**；已有“树荫观察”时选 **保留想法并关联已有笔记**，保留想法正文并关联该笔记。

独立脑图与自由白板中的思维导图模板是两种工作方式。父子、左右关联和键盘命令见 [脑图操作](#mind-maps)。

![独立脑图：两层关系、双向关联与展开的想法](https://raw.githubusercontent.com/YuguangLi-lab/obsidian-thoughtspace/main/docs/images/brain-research.png)

1.3.35 真实界面，摄于专用自制练习库；用于说明操作，不代表研究结论。

### 第五步：填写原生属性并返回

1. 普通 Markdown 白板从标题菜单选 **原生属性与 Markdown**；脑图从 **脑图菜单** 选同名项。
2. 在正常 Obsidian Properties 中添加 `status` 或 `tags` 等属性。例如给本研究标记 `research/urban-cooling`。
3. 编辑完成后，在当前原生页菜单选 **返回白板**。也可运行 **切换白板与原生属性**，在同一标签页往返。

若还有同文件原生页打开，白板会只读保护布局。先保存并关闭其他同文件页，再从保留的原生页返回；不要为解除只读而丢弃草稿。详见 [属性与搜索](#obsidian)。

### 第六步：记录视频或音频中的一个时间点

1. 打开 **ThoughtSpace 音视频笔记**，选择自己的本地媒体；在线视频可选择 **B 站 / YouTube 在线视频** 并粘贴真实来源链接。
2. 点 **记下此刻** 固定时间；本地媒体在 **当前草稿**、在线视频在 **记录摘录** 区域写“此处说明了观测方法”，需要画面时再截图。
3. 点 **保存摘录**，从时间轴把已保存摘录发送到“城市降温研究”白板。
4. 点击摘录时间戳，检查能回到匹配来源和时间点。

加载或平台限制会影响在线视频；没有匹配白板播放器时，可回到独立媒体工作区。原生打开和草稿边界见 [音视频](#audio-video)。

### 第七步：编排成文章

1. 回到普通白板，打开 **工作区 → 白板写作模式**。
2. 在 **材料库** 阅读证据，拖到 **编排**，按“问题—观察—待核实结论”排序。
3. 在 **写作** 编辑正文，切 **预览** 检查来源链接。
4. 点 **生成草稿**，打开独立 Markdown 文件继续写作。

编排不改写原材料；生成的草稿也不会自动反写白板文章。更多引用和安全重建步骤见 [写作](#writing)。

![白板写作：编排文章与查看材料库](https://raw.githubusercontent.com/YuguangLi-lab/obsidian-thoughtspace/main/docs/images/writing-research.png)

1.3.35 真实界面，摄于专用自制练习库；用于说明操作，不代表研究结论。

### 最后：检查保存，再回来继续

等待普通白板 **已保存**，脑图的待保存、保护或错误提示也需处理完；确认笔记正文、媒体摘录和独立草稿各自保存。下次运行 **继续上次白板**，按最近访问打开有效白板；没有有效记录时进入空间总览。它恢复文件中已保存的位置，不恢复未保存输入。

## 3. 入口与内容保存在哪里

| 要做的事 | 入口 |
| --- | --- |
| 浏览白板和材料 | Obsidian 最左侧 **ThoughtSpace 侧边栏** 图标 |
| 查看空间总览 / 最近打开 | 命令 **打开空间总览**；普通白板 **工作区 → 打开知识空间** |
| 直接继续最近有效白板 | 命令 **继续上次白板** |
| 新建普通白板或独立脑图 | 侧栏 **新建 → 新建白板或脑图…**；同名命令 |
| 建立新笔记卡片 | 普通白板左侧悬浮工具栏 **＋ 新建卡片** |
| 插入笔记、PDF、图片、媒体或表格 | 普通白板左侧悬浮工具栏 **插入内容** |
| 查找较少使用的功能 | **更多白板工具**，可搜索并按分类浏览 |
| 整理、阅读、写作和导出 | 普通白板顶部 **工作区** |
| 原生 Properties 往返 | Markdown 白板菜单 **原生属性与 Markdown**；原生页 **返回白板** |
| 调整对象样式 | 普通白板选中对象后的上下文工具栏 |
| 背景、网格、缩放和总览 | 普通白板底部视图工具条 |
| 播放音视频并摘录 | Obsidian 最左侧 **ThoughtSpace 音视频笔记** 图标 |

普通白板使用自由画布，侧栏提供 **卡片 / 白板 / 任务 / 大纲**，左侧小工具栏负责添加和选择，上方选中对象后显示格式操作。独立脑图围绕当前中心显示父子与关联，使用自己的顶栏和 **脑图菜单**。窄窗口部分控件收紧或横向滚动；悬停图标查看名称，键盘聚焦也可访问菜单。

| 对象 | 内容保存在哪里 | 在本练习中的用途 |
| --- | --- | --- |
| 白板文本 / 脑图想法 | 当前 `.md` 的布局区，或 `.thoughtspace` 文件 | “街道树荫如何影响行人感受到的热？” |
| 笔记卡片 | 正文在原 Markdown；白板保存引用和外观 | “树荫观察”长期笔记 |
| 图片、PDF、音视频卡片 | 来源文件；白板保存引用和布局 | 街道照片、研究论文、访谈 |
| Markdown 白板属性与正文 | 白板 `.md` 的原生 YAML 与布局区外 Markdown | 研究标签、状态、摘要 |
| 生成的文章草稿 | 独立 Markdown 文件 | 研究小结 |

分组框是当前白板的组织结构，不是文件夹。子白板是独立文件；自由白板的“新建子白板 / 转换为子白板”继承父板格式。独立脑图关系弹窗中的“新建白板”仍生成旧格式文件。复制或另存白板保留来源材料引用，不会自动复制每篇笔记或附件。

## 4. 选择、移动、缩放与键盘

以下是新安装的默认操作。已有安装可能保留个人偏好，实际操作以 **设置 → ThoughtSpace Whiteboard → 鼠标与键盘** 为准。

| 操作 | 默认效果 |
| --- | --- |
| 空白处左键拖动 | 平移画布 |
| 空白处右键拖动 | 框选对象；按住 Shift 累加选择 |
| 右键单击 | 打开当前位置或对象菜单 |
| 中键拖动 | 平移画布 |
| Shift + 左键拖动空白处 | 临时框选 |
| 空格 + 左键拖动 | 临时平移 |
| 滚轮 | 以鼠标位置为中心缩放 |
| 拖动对象 | 移动该对象或所选对象 |
| 拖动对象右下角手柄 | 调整大小 |

按住 Shift 单击卡片可加入或移出选区；按住 Shift 拖动已选卡片会保留多选，并在启用轴向锁定时沿水平或垂直方向移动。拖动右下角手柄只调整该卡片的大小，保留其他已选卡片；启用比例锁定时，Shift + 拖动手柄按原比例缩放。松开鼠标时，即使指针已移到画布外，也会结束本次操作。

点击左侧悬浮工具栏的 **框选** 工具后，左键也可以框选。普通对象与选框相交即可被选中；分组框需要被完整框住，避免把覆盖大范围的分组误选进去。

设置中有 **默认方案、左键框选、触控板** 三个鼠标方案，还可单独调整三个按钮、滚轮方向、速度、缩放中心与防误触距离。滚轮设置为平移时，用 `Ctrl/Cmd + 滚轮` 缩放；触控板捏合保持缩放。

### 画布获得焦点、未编辑文字时

| 按键 | 操作 |
| --- | --- |
| `F` | 适应全部内容 |
| `Shift + F` | 聚焦所选 |
| `F2` | 原位编辑所选文本或笔记 |
| `Enter` | 普通白板中编辑所选内容；导图中有专门含义 |
| `Ctrl/Cmd + F` | 搜索当前白板 |
| `Ctrl/Cmd + Z` | 撤销白板操作 |
| `Ctrl/Cmd + Shift + Z` | 重做白板操作 |
| `Delete` / `Backspace` | 移出所选对象，保留关联文件 |
| 方向键 / `Shift + 方向键` | 普通对象默认移动 1 / 10 像素 |
| `Alt + ← / →` | 返回上一视角 / 前进到下一视角 |
| `Esc` | 取消当前连线、框选等操作，退出相关工具状态 |

可关闭白板快捷按键、方向键移动或删除键功能；方向键步长也可修改。文字编辑器、输入框、菜单和导图主题会优先处理自己的按键。

要绑定自己的组合键，打开 **Obsidian 设置 → 快捷键**，搜索 `ThoughtSpace`。插件提供新建、撤销、复制、删除、主题、搜索、整理、阅读及视角命令；这些可绑定命令本身不额外分配默认组合键。

独立脑图另有 **脑图：添加父节点、脑图：添加子节点、脑图：添加左侧关联节点、脑图：添加右侧关联节点** 四条命令，均没有默认热键，作用于当前活动脑图的中心，打开原有确认弹窗。文字输入、正在组字、只读、锁定或编辑/创建进行中时不执行。命令面板关闭后若恢复到输入框焦点，执行仍会受输入保护；先完成并退出编辑，再使用关系命令。完整 OS 输入法的开始、提交、结束流程尚未完成原生确认，见 [1.3.35 验证边界](../qa/RELEASE-1.3.35.md#完整进程重开与输入边界)。

### 找回刚才的位置

运行 **继续上次白板**，使用已有最近访问记录选择有效白板，不按文件修改时间选择；没有有效项时进入空间总览。也可打开空间总览的 **最近打开** 分类。白板恢复已保存的相机与脑图状态；若要在自由白板命名保存“材料区”和“写作区”，使用 [常用视角](#appearance)。这些位置入口不是未保存草稿恢复。

## 5. 写想法、笔记、Markdown、表格和公式

### 选择文本框还是笔记卡片

- 双击空白处或点击 **文本**，适合快速写想法，内容保存在白板中。
- 点击 **新建卡片**，适合建立可在其他白板和原生 Obsidian 中复用的笔记。
- 点击 **插入内容 → 已有笔记**，引用已有文件；再次编辑卡片会修改原 Markdown 正文。
- 文本框右键 **转换为笔记**，可以把白板文字转为独立笔记。

双击文本或卡片正文进入编辑。支持 Obsidian 原生实时预览；若当前宿主环境不兼容，会回退为 Markdown 源码编辑。点击画布底部操作条的 **保存**，或按 `Ctrl/Cmd + Enter` 完成本次编辑；`Esc` 取消本次修改。保存失败时草稿会保留，操作条显示 **重试**，也可先复制草稿。窄窗口仍保留保存状态，图标可通过悬停查看说明。

例如，文本框中可以输入：

```markdown
## 城市降温研究
- 树荫观察的时段和位置是什么？
- 哪些证据还需要核实？

> [!note] 我的判断
> 将摘录与自己的解释分开。

行内公式：$E = mc^2$

$$
\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i
$$
```

编辑工具栏提供常用 Markdown 操作，也可直接输入标题、列表、引用、代码和链接。任务复选框在文本预览中只读，需要进入编辑后修改。

### 插入表格

1. 使用 **插入内容 → 表格**，或在空白处右键 **在此添加表格**。
2. 新建后第一个表头被选中，直接输入名称。
3. 填写表头和单元格；已有文本编辑区也有表格按钮。
4. 完成后保存；表格过宽时可以在框内横向滚动。

```markdown
| 材料 | 核心观点 | 下一步 |
| --- | --- | --- |
| 树荫观察 | 待核实的描述 | 补充时段与位置 |
| 研究论文 | 不同解释 | 比较观测方法 |
```

表格默认根据内容自动适配宽高；手动拖动尺寸或关闭自适应后，保留手动尺寸。表格直接显示单元格网格，不再套外层文本框；透明底色与细单元格线区分行列，预览和原位编辑保持一致。

这里的表格是 Markdown 内容；数学公式用于排版，不会把表格变成自动计算的电子表格。

### 标题与大小

笔记卡片右键 **修改卡片标题** 可设置白板上的显示标题，不等同于重命名原笔记。需要修改文件名时，使用笔记的 **重命名笔记** 或 Obsidian 文件列表。

选中或悬停卡片后，上方操作条可直接编辑、在右侧阅读笔记、打开关联预览、切换自适应和折叠。文本操作条提供编辑、自适应高度和折叠。自适应按钮高亮表示开启，再次点击可关闭并保留当前尺寸；右键菜单中的对应入口继续保留。手动调整尺寸后，若希望恢复随正文适应，请重新启用对应功能。图片和 PDF 调整尺寸保持内容比例。

鼠标从正文移向上方操作条时，经过中间空隙也会保持显示；离开卡片及操作条附近后再收起。

笔记操作条用 **编辑 / 阅读** 标明常用入口，其他功能保留图标。折叠后的笔记和文本可直接点击标题条内的向下箭头展开；上方次要阅读入口仍支持选中、悬停或键盘聚焦。长篇笔记出现 **继续阅读** 时，点击按当前可见区域向下滚动，到底后提示消失。空白笔记点击 **写下第一行想法** 即可原位编辑。

顶部样式工具栏分为对象 / 模式切换和具体参数两行；窄窗口按字段换行，极窄窗口可横向滚动查看。


### 卡片样式

选中一张或多张 Markdown 卡片或文本框，在顶部 **卡片** 中选择 **透明 / 实色 / 彩色标题栏 / 双线纸笺 / 索引卡 / 便签卡**。彩色标题栏显示卡片标题；在 **背景 → 卡片颜色** 调整标题栏颜色，也可使用自定义颜色。双击标题栏中的标题可修改卡片名称，不会重命名源笔记；未修改就退出，不会生成固定别名。双线纸笺增加细双框和回形针装饰，背景颜色会同时应用于纸面与双线间隙。固定尺寸卡片切换样式时保留当前阅读位置。

**索引卡** 使用侧边色条与独立标题，适合整理概念和阅读摘录；**便签卡** 保持正文优先，使用柔和底色与小折角。两种新样式的颜色均跟随 **背景 → 卡片颜色**，支持自定义边框和深色主题。缩略图随同色选择显示当前颜色，窄面板自动换行；混合颜色选择使用主题色预览，不会改变卡片原有颜色。

在 **设置 → ThoughtSpace → 卡片与笔记 → 默认卡片样式** 选择之后新建、拖入或从卡片库插入的笔记样式。旧卡片不自动改变；图片、PDF、网页及新建文本保持各自原有外观。样式可撤销、复制粘贴并随白板保存；切换时保留编辑草稿、折叠状态及 Obsidian 正文字体。

文本框也可手动选择以上六种类型，仍然是文本，不会转换为笔记文件；彩色顶栏只绘制色带，不添加文件标题。支持与笔记卡片混选，锁定对象不能改样式。

**降级兼容：** 文本框的彩色顶栏、双线纸笺、索引卡和便签卡需要 ThoughtSpace 1.3.26 或更新版本。1.3.25 遇到这类白板会报错并拒绝打开，不会自动转换。降级前请在新版中将这些文本框切回透明或实色并保存；保留白板备份。

## 6. 放入已有笔记、图片和 PDF

### 从 Obsidian 拖入

1. 打开目标白板，并让文件列表或搜索结果可见。
2. 拖动已有 Markdown、PDF 或图片到白板的目标位置。
3. 松手后生成引用卡片；原文件保留在原位。
4. 多选文件后可以批量拖入；一次导入的整批对象可一起撤销。

也支持从可识别的 Obsidian 内部链接拖入。不要用跨仓库的链接代替当前仓库中的文件。

### 网页卡片与图床快捷操作

使用 **插入内容 → 网页卡片** 输入 HTTP(S) 链接，也可以在空白处粘贴或拖入单个网页链接。支持连线、调整大小和折叠。粘贴或插入后默认在 640 × 460 卡片中预览网页；网站禁止嵌入时使用 **打开网页**。默认只显示域名和网址，不自动抓取标题。导出原生 Canvas 后保留链接节点。

图片上方的云朵按钮可通过已配置的 **极速图床** 上传；已上传时点击复制链接。本地附件保留，可用于加载回退。

### 插入和查看图片

使用 **插入内容 → 图片**，选择仓库里的图片，或 **从电脑导入图片…**。从电脑导入会在仓库保存附件；已有仓库图片只是被引用。

图片按原始比例显示，双击可打开查看。可选图床需要另外安装并配置“极速图床”，再在 **图片与图床** 设置中启用；默认流程不要求图床，启用后导入图片会按该插件设置上传并保留本地附件。数据说明见[安全与隐私说明](../SECURITY.md)。

### 阅读 PDF 页面

1. 使用 **插入内容 → PDF 卡片**，或直接拖入 PDF。
2. 悬停或聚焦卡片，使用浮动翻页控件；也可右键 **选择 PDF 页码…**。
3. 选中 PDF 卡片后，`PageUp` / `PageDown` 翻页，`Home` / `End` 跳到首页或末页。
4. 右键 **右侧阅读 PDF**，在原生阅读器中查看正文和选择文字。

页数需要首次读取后才可完整导航。折叠 PDF 会保留当前页码和展开前尺寸；在输入框中打字时不会被上述翻页键打断。

### 粘贴 PDF / PDF++ 引用

在白板的 **白板操作** 中搜索 **粘贴 PDF / PDF++ 引用**，粘贴从 PDF 阅读器或笔记复制的 wiki/Markdown 链接、引文或矩形嵌入。预览来源后点击 **加入白板**（⌘ / Ctrl + Enter），一次导入生成一张可编辑卡片，可单步撤销/重做。再次导入完全相同的内容会定位已有卡片。

从 Markdown 笔记复制相对链接时，填写该笔记的完整仓库路径。同名 PDF 无法确定时会阻止导入，请补全文件路径或来源笔记；不会任意选择一个文件。PDF 定位参数和独立的笔记块链接分别保留，卡片的来源菜单可 **复制原始 PDF 引用**、回到来源或 **仅打开 PDF 页**。

PDF++ 是可选插件。ThoughtSpace 保留 page、selection、annotation、rect、offset、color 及未知定位参数，使用 Obsidian 公共打开链接接口；高亮、批注和矩形嵌入是否显示取决于阅读器及 PDF++。未启用 PDF++ 时可回退到页码。这里不安装或调用 PDF++ 的复制命令，不改写 PDF 或来源笔记，也不建立 PDF++ 高亮到白板的自动反向链接。原始复制文本作为白板卡片的来源快照保留；修改卡片正文不会改动该快照。不同原始复制语法分别保留，完全相同的原文、上下文与内容才会去重。通过 Obsidian 改名时，可点击链接与矩形嵌入跟随更新，代码示例和原始快照保持不变；新导入卡片默认自动适应内容高度。

### 从笔记或 PDF 摘录

1. 先打开目标白板。
2. 在原生文件列表右键笔记或 PDF，选择 **ThoughtSpace · 右侧阅读与拖放摘录**；也可运行 **在右侧阅读 PDF 并摘录**。
3. 选中需要的文字，再拖到白板；PDF 选区上方还提供 **拖到白板** 手柄和 **加入白板** 按钮。
4. 检查新摘录中的来源链接；笔记摘录保留可用的标题或块来源，PDF 摘录保留页码等可用定位信息。

扫描版 PDF 必须先有可选择的文本层；本插件不提供 OCR。通过 Obsidian 改名或移动原文件可更新支持的引用，但不要把普通正文中的示例路径当成必然自动更新的来源。

选中文字拖到符合条件的笔记卡片上，落点提示会变为 **追加证据**；拖到空白处则新建摘录。松手前先核对落点，避免把原本想单独保存的摘录追加进另一篇笔记。

需要批量拆分结构化材料时，运行 **打开材料工作台**，选择来源笔记，预览片段并勾选要导入的内容，再检查分组与来源链接选项。工作台也提供把大纲转换为主题树的流程。撤销这些笔记在白板中的位置，不会删除已创建的摘录文件。

## 7. 连线、父子关系和折叠

### 建立和修改关系

1. 从对象边缘的连接点拖到另一对象，或使用 **连线** 工具依次选择两端。
2. 选中连线，在顶部修改路径、箭头、颜色等样式。
3. 使用 **关系说明** 或右键 **修改关系说明**，说明这条关系的含义。
4. 需要反向时选择 **反转连线方向**；仅删除关系时选择 **删除连线**。

曲线、直线和圆角折线都可使用。**更多白板工具 → 连线统一为直线** 会修改当前白板全部连线，并影响后续新建连线。选中一条线后，**当前路径应用到全部连线** 可统一其他路径；支持撤销。

### 折叠父子分支

普通关系线与可折叠的父子分支有区别。右键普通连线，选择 **允许折叠（设为父子分支）**，才把它作为父子关系使用。

- 父节点的减号折叠分支；加号只展开下一层。
- 父节点右键可选 **展开下一层** 或 **展开所有子节点**。
- `Ctrl/Cmd + Shift + Enter` 在画布中切换折叠或逐层展开。
- 不允许循环父子关系，也不允许一个节点同时拥有多个父节点。

折叠后显示为最大 **180 × 40** 的紧凑标题条；点击标题条右侧箭头或双击可展开并恢复原尺寸。图片也可以通过上方按钮或右键菜单折叠。文本、笔记和分组保留边框，图片、PDF、音视频及子白板不再带装饰外框。

折叠隐藏内容但不删除节点、连线或来源文件。对象自身的正文折叠、分组折叠和子节点分支折叠是不同操作。

### 展开时自动让位

可以先折叠组内卡片，再把分组缩到能容纳可见标题条的大小；之后逐个展开时会按需撑开，再收起会回到手动调整后的大小，不必保留原先的大框。

自由白板中的正文、图片、PDF、音视频及分组展开时，会按实际可见尺寸为内容留出空间：受影响的邻近对象沿原列向下移动，所属分组按需向右或向下扩大。Markdown、图片或公式渲染完成后继续增高时，也会继续让位。连线和来源引用保持不变，分组不会因扩框而自动吞入原本在外部的卡片。

长篇笔记达到卡片高度上限后，直接在卡片内滚动继续阅读，透明背景不变。滚动到正文边缘也不会带动画布；Ctrl / Command + 滚轮仍用于白板缩放。代码块横向滚动与正文纵向滚动可以同时进行。

展开和让位属于同一次撤销；收起时会回收自动让出的空间，恢复邻近对象与分组原尺寸。多张卡片连续展开时，只回收已经收起的部分，仍展开的内容继续保留空间。自动测量或编辑后的最新内容尺寸会保留，下次展开无需重新拖大。恢复记录随白板保存，关闭重开后仍可使用。

手动拖动、缩放、增删对象或调整关系后，会以你的新布局为准，停止恢复旧位置；仅改文字或颜色不影响有效记录。旧版已让出的空白没有原位置记录，不能可靠地自动还原，可撤销旧展开或手动整理后再开始新的展开/收起操作。普通拖动、缩小、手动调整分组和移入分组仍按原操作执行，不触发全板整理。已明确关闭自动排版的思维导图保留内部手工位置，只将整棵树作为单元避让外部内容。

锁定节点及含有锁定成员的移动单元不会被挪动。锁定分组空间不足、共享重叠分组等无法保留原归属的情况，会提示调整或解锁，并取消本次布局变更。已经混叠的旧节点可先收起再展开，触发对应区域的让位；不会在打开白板时强行重排全部历史布局。

### 连线创建与拖动间距

普通白板从连线点拖到空白处，仍立即创建文本；按住 **Alt / Option** 松手可选择文本、表格或已有 Markdown/PDF 引用。也可以聚焦连线点按 **Shift + F10**，用方向键和 Enter 选择，Esc 取消。取消菜单或文件选择不会留下节点和连线；思维导图原有的快速子主题操作不变。

开启对齐辅助线后，同一行或列的相邻卡片可显示等间距数字并吸附；原有边缘/中心对齐优先，Alt 暂停拖动吸附。缩小白板时，普通连线起点仍保持至少 30 屏幕像素的点击范围。

## 8. 用分组和子白板控制规模

### 分组框

双击组内空白处即可选中分组，随后拖动上、下、左、右边线调整范围；成员保持原位。边线中央仍用于连线，原有右下角调整入口保留。双击标题继续重命名，双击组外空白仍创建文本框。锁定分组须先解锁。

1. 先选中一组对象，再点击 **分组框**，给它们命名。
2. 没有选择对象时，也可用分组工具拖画范围，松手后命名。
3. 右键分组可重命名、选择框内内容、贴合内容、整理或折叠。
4. 要把其他对象放进去，选中对象后使用 **工作区 → 移入已有分组**，查看目标和边界预览，再应用。

**移除分组框（保留内容）** 只移除框。分组可以嵌套；锁定内容会限制相应的移动和整理。用 **分组总览 / 分组预览** 快速浏览各组。

选中分组框，顶部工具栏可调整 **分组样式、分组背景、标题分割线**。可设为透明、选择预设或自定义底色，用实线、虚线、点线或无分割线区分分组。

### 子白板与复用

使用 **插入内容 → 子白板** 新建下一级白板；**引用白板** 则加入已有白板。自由白板的新建与转换子白板继承父板格式：Markdown 父板创建 `.md`，旧格式父板创建 `.thoughtspace`。双击子白板卡片或右键 **进入子白板** 进入，通过顶部导航回到上一级。

把“问题总览”放在父白板，把某个问题的大量证据放在子白板，可减少单张白板的拥挤。插件会阻止循环嵌套。

选中需要复用的对象，打开 **更多白板工具 → 复用到其他白板**。先检查目标及复用选项，再执行；复用笔记引用并不自动意味着复制原 Markdown 文件。

## 9. 独立脑图与思维导图模板

### 独立脑图：围绕当前中心看关系

“城市降温问题树”使用独立脑图。通过 **新建白板或脑图… → 脑图白板** 建立，可使用旧格式或 Markdown。

1. 空板点 **添加知识节点**，选 **先记想法 / 新建笔记 / 引用已有笔记 / 新建白板**，确认来源和名称。
2. 点击节点将它设为中心；上方是父关系，下方是子关系，左、右是双向关联，不代表同级子主题。
3. 中心四侧加号打开对应创建弹窗。关系菜单也可为已有节点建立 **添加子级关系 / 添加父级关系 / 添加关联**。
4. **脑图菜单** 选择 **显示 1 层** 到 **显示 5 层**，缩小或扩大关系范围；范围包含关联跳数。返回、前进、搜索和固定节点帮助在问题间浏览。
5. 点节点展开按钮阅读内容，点来源入口打开文件；折叠或中心切换不删除节点、关系或正文。

要把“树荫”想法整理为长期笔记，节点菜单选 **整理成笔记**。**新建笔记** 会生成文件并保留节点关系；**保留想法并关联已有笔记** 保留原想法正文、标题和关系，增加或复用选中笔记的引用并建立双向关联，不改目标正文。撤销关联只撤销本次白板事务；撤销新建转换不会删除已生成文件。

给其他节点加笔记关联时，可直接选节点菜单 **关联已有笔记…**，选择文件、核对左/右位置再确认。同一对节点已有普通关联时会提示编辑已有连线，不自动合并或重复添加。选择 **新建白板** 时，关系弹窗生成旧格式子白板；若需要 Markdown 子白板，可先用通用新建创建，再引用。详见 [想法与已有笔记](markdown-boards.zh-CN.md#想法与已有笔记)。

### 自由白板中的思维导图模板

这是在自由画布上创建和排版主题树，和上述独立脑图的中心关系浏览不同。

1. 运行 **新建思维导图**，或使用 **插入内容 → 思维导图模板**；这两个入口都会打开一张新的普通旧格式模板白板。
2. 选择模板，例如 **灵感发散、项目计划、阅读笔记、研究设计、论证结构、复盘改进、SWOT 分析、组织分工**。
3. 编辑中心主题，然后逐层补充自己的内容。
4. 打开 **更多白板工具 → 导图布局与配色**，进入 **思维导图工作台**。

也可在当前白板插入 **中心主题**，或从 **工作区** 切换白板模式。已有普通文本不会因此全部被强制变成主题树。

| 导图操作 | 效果 |
| --- | --- |
| 点击主题边缘加号 | 创建已连线的子主题并编辑 |
| 从主题拖线到空白处 | 创建子主题并排版 |
| `Tab` | 在适用的主题编辑状态保存并新增子主题 |
| `Enter` | 在适用的主题编辑状态新增同级主题 |
| `Shift + Enter` | 编辑主题时换行 |
| 退出编辑后按方向键 | 在主题树的可见主题间导航 |
| 退出编辑后按 `Shift + Tab` | 返回父主题 |
| `F2` | 编辑所选主题 |

编辑表格、列表、公式或代码时，`Enter` / `Tab` 优先编辑内容；不要把它们一概当成新增主题键。

工作台提供 **双向导图、向右逻辑图、向左逻辑图、向下组织图、向上组织图**，可调整分支间距、展开层级、配色和线型。检查预览后应用；有多棵树时先确认 **主题树** 选项。

启用 **自动保持模板布局** 后，编辑相应主题树会继续遵循其布局。工作台还可导入大纲、查找替换、分支演示，导出整棵树或所选分支的 Markdown / SVG。

## 10. 调整样式、背景和常用入口

独立脑图可按每板设置背景、节点底色、节点边框、标题/关系标签文字和连线颜色。点击顶栏 **脑图配色** 图标可直接进入；原来的 **脑图设置 → 背景与配色 → 脑图配色…** 和底栏 **白板背景 → 脑图配色…** 入口也保留。节点边框颜色同时作用于展开的阅读框，留空时随主题和节点底色调整。弹窗内可同时查看节点与连线示例。颜色选择器或 #RGB/#RRGGBB 可预览，留空跟随当前主题；取消或 Esc 还原保存状态。确认与恢复默认支持撤销/重做及重开；恢复默认只清除五项颜色，保留纸张/图片背景参数，不透明图片仍可能遮住底色。低对比提示不替换用户选择，原生控件与 Markdown 正文格式保持已有配色。

普通白板左侧 **插入内容** 使用紧凑的分类菜单；悬停某项可查看用途，所有原有入口仍可访问。选中多个对象时，顶部集中提供批量操作，单张卡片的操作条在悬停或键盘聚焦时出现；折叠后的展开按钮仍可直接使用。窄面板的格式参数可横向滚动，键盘聚焦会自动显示对应控件。

选中文本或笔记卡片后，顶部工具栏按对象类型提供 **编辑、卡片、文字、背景、边框**。按需要调整卡片样式、字号、字体、文字颜色、对齐、填充、透明样式或边框；批量选中时只显示适用操作。边框编辑和样式粘贴作用于文本、笔记与分组；无边框对象不提供边框设置，分组同时保留背景与分割线。

未编辑时，顶部只常驻分类，点击分类展开参数；再次点击或 Esc 收起。选中卡片通过顶部“编辑”进入正文；其他卡片悬停仍保留就近编辑入口。切换样式会保留正在编辑的草稿与选区。窄窗口可能只显示图标或需要横向滚动，先悬停查看名称。**白板操作** 中可以复制和粘贴对象样式。

底部背景入口或 **设置 → ThoughtSpace → 白板 → 画布背景** 支持点阵、网格、纯色、纸张纹理和自定义图片。纸张可调整颜色与纹理强度；背景图片可设置填满、完整显示、平铺和透明度，图片保存在当前仓库的插件目录中。

背景外观和网格吸附分开控制。底部可调整网格与缩放；**适应** 显示全部内容，小地图帮助理解当前位置，窄窗口可能自动收起小地图。

顶部 **常用视角** 可保存、搜索、改名、更新和排序视角。例如分别保存“材料区”和“写作区”。视角只保存位置与缩放，不保存当时的内容版本。

<a id="settings"></a>

### 设置布局、语言与偏好配置

打开 **设置 → ThoughtSpace Whiteboard** 或工作台设置，可看到 **界面、卡片与笔记、白板、鼠标与键盘、阅读、文件与归档、图片与图床、偏好配置** 八个分类。新建卡片的样式、宽度、字号与连线默认值集中在 **卡片与笔记**；画布背景、小地图、网格间距、对齐辅助线与预览选项集中在 **白板**。

顶部语言选项提供 **跟随 Obsidian、简体中文、English**。自动模式在 Obsidian 使用中文时显示中文，其他语言显示英文。本次语言切换覆盖设置页及纸张、背景图片弹窗，不改变其他菜单和白板工具栏，也不会翻译笔记内容、文件名或路径。

搜索框会跨分类查找设置；清空搜索或点击分类即可返回分类视图。**界面、卡片与笔记、白板、鼠标与键盘、阅读** 提供 **恢复本分类默认值**，确认后仅重置该分类，不重置其他分类，不修改已有卡片样式、笔记或文件。会移动实际文件的归档操作另有确认步骤。

在 **偏好配置 → 导出偏好配置 → 查看与复制** 中查看并复制 JSON。迁移时打开 **导入偏好配置**，粘贴 JSON 或选择 `.json` 文件，先点 **检查配置**，再明确点击 **应用配置**。修改 JSON 后需要重新检查；仅打开或检查配置不会应用设置。

配置只包含支持迁移的外观、阅读和操作偏好，不是仓库备份。不包含目录与图片路径、收藏、归档、图床上传、密钥、语言或自定义纸色与纹理参数。自定义背景图片不会随配置迁移：使用图片背景时，导出会略过背景模式，导入后保留目标仓库原来的背景；其他未包含的设置同样保持不变。纸张细节与本地背景图片请在目标仓库单独设置。

## 11. 原生属性、材料搜索与整理

### 为“城市降温研究”填写 Properties

1. Markdown 普通白板标题菜单或脑图 **脑图菜单** 选择 **原生属性与 Markdown**。
2. 在 Obsidian 原生页编辑属性，例如 `tags: research/urban-cooling`、`status: reading`；属性类型和显示方式由 Obsidian 管理。
3. 原生页菜单点 **返回白板**；也可运行 **以白板打开当前 Markdown** 或可自行绑定的 **切换白板与原生属性**。
4. 若提示其他原生页仍打开，用 **定位原生页** 找到它们，保存并关闭其他同文件页，再从保留页返回。

插件保留 Obsidian 对 `.md` 的默认打开方式；已有白板页可能被复用。从文件列表或快速切换器打开后若进入原生 Markdown，可用文件列表的 **以白板打开** 另开或定位白板；当前原生页的 **返回白板** 执行安全的同页交接。不要仅添加 `thoughtspace: board` 属性把普通笔记当成白板；还需要完整布局区。

旧 `.thoughtspace` 白板继续使用，没有原生 Properties 页面。需要单文件 Markdown 时，普通白板标题菜单运行 **另存为 Markdown 白板**，得到独立副本；原文件和已有链接保留，不自动迁移材料。两格式复制范围见 [新旧格式另存](markdown-boards.zh-CN.md#新旧格式另存)。

### 先预览再整理

1. 选择需要整理的对象或分组，打开左侧悬浮工具栏的 **整理白板**，或 **工作区 → 整理白板**。
2. 确认整理范围，选择排列或按类型、颜色、阅读状态、连通关系归类。
3. 调整列数、间距等参数；需要时勾选 **生成命名分组框**。
4. 在 **原布局 / 整理后** 之间比较，确认没有误选其他内容。
5. 点击 **应用布局**；决定是否勾选 **应用后定位到结果**。

常用参数可在 **保存与复用预设** 中保存。锁定内容、折叠分支及分组边界可能限制可应用的布局，按窗口提示处理；对齐功能可能让对象重叠，先看预览。

<a id="search"></a>

### 当前白板搜索与原生搜索

搜索窗口关闭再打开时，会在当前白板会话中保留关键词、筛选、正文搜索开关与选中项；不同白板分别记忆，关闭白板会话后释放。

在普通白板的完整搜索窗口中组合关键词、类型、分组、颜色与 **阅读状态**，展开 **材料清单**，填写名称后点击 **保存查询**。例如类型选 PDF、阅读状态选待读，就能保存“城市降温：待读 PDF”清单。清单随当前白板文件保存；选择清单会按当前材料和阅读状态重新计算结果，不保存结果快照或整篇正文。可用清单旁的按钮重命名、删除；删除可通过白板撤销恢复。原分组被删除时清单保持空结果，调整筛选后可另存查询。笔记、文本、图片与 PDF 结果行可直接修改阅读状态，锁定对象除外；保存失败会保留输入并提示重试。

独立脑图的搜索用于节点导航，不提供上述材料清单。普通白板的 `Ctrl/Cmd + F` 或 **更多白板工具 → 搜索白板** 用于当前白板定位。需要查缺失引用、孤立或锁定对象时，打开 **白板操作 → 白板检查**。

插件默认在 `ThoughtSpace/白板搜索/` 自动生成 Markdown 索引，让 Obsidian 原生搜索找到白板文本、卡片标题、分组名和连线说明；点索引中的定位链接返回对象。原笔记正文仍通过原 Markdown 文件搜索。

PDF 索引包含文件名与页码，不包含全文或 OCR。可在 **设置 → ThoughtSpace → 白板 → 白板原生搜索** 停止自动更新，或运行 **重建白板原生搜索索引**。手动修改过的索引会保留并提示，不建议把生成索引当成写作原稿。

### 卡片资料库、看板和 Bases

1. 点击 Obsidian 左侧 **ThoughtSpace 资料库**，或运行 **打开卡片资料库与看板**。
2. 先选择 **资料范围**：当前白板、卡片目录或整个仓库。
3. 用标题、路径、标签、状态、优先级和截止日期筛选。
4. 在 **资料表** 中编辑属性，或在 **进度看板** 中拖动卡片改变状态；修改即保存到原笔记。
5. 使用 **保存筛选视图** 留下常用筛选，或 **自定义字段** 添加已有属性列。

内置属性是 `thoughtspace_status`、`thoughtspace_priority`、`thoughtspace_due`；状态包括待整理、进行中和已完成。阅读桌里的阅读状态是白板对象状态，和资料库中的笔记进度属性不是同一套字段。

**打开 Bases** 会在 `ThoughtSpace/视图/` 生成原生 `.base` 文件；需要 Obsidian 的 Bases 功能可用。当前白板范围是导出当时的文件列表快照，属性值仍从笔记读取；之后新增白板卡片不会自动加入这份范围快照。也可 **导出 CSV** 保存筛选结果。

### 按标签归档

默认卡片根目录为 `ThoughtSpace/卡片`。**文件与归档 → 自动按标签归档** 默认开启，只自动管理该目录内的笔记；例如 `#研究/阅读` 对应根目录下的 `研究/阅读`，无标签时进入“未分类”。

调整根目录后需点击 **保存目录**，更改只影响之后的新建与归档。归档会实际移动文件并先备份；这类移动不属于白板布局撤销。已有任意目录笔记拖入白板，本身不会触发复制或移入卡片根目录。

## 12. 阅读桌与白板写作

在“城市降温研究”普通白板打开 **工作区 → 打开阅读桌**，集中阅读已收集的材料：左侧搜索和筛选材料，在 **内容、目录、关联** 之间切换；右侧阅读正文。顶部可修改阅读状态、右侧打开原文或定位白板，底部可翻篇，`Alt + ← / →` 切换材料。

阅读桌包含笔记、文本、图片与 PDF。PDF 使用 Obsidian 原生嵌入预览，与搜索材料清单共享白板对象的待读、在读、已读状态。

PDF 的文字选择与摘录使用前述右侧原生 PDF 阅读器。阅读桌或写作参考的长文预览可能截断，窗口提示时打开原文查看全文。

编辑笔记并使用关联笔记工具时，可以选取笔记中的标题或块，点 **阅读引用原文** 预览范围，再插入链接或嵌入正文。

<a id="writing"></a>

### 把材料变成文章

1. 打开 **工作区 → 白板写作模式**，在右侧 **材料库** 搜索当前白板材料。
2. 点击材料阅读，把需要反复查看的材料保留在 **固定参考**。
3. 用 `＋` 插入正文，或拖动材料到 **编排**；也可 **新建章节**，按“研究问题、观察证据、待核实结论”排序。
4. 设置章节标题、标题层级、批注和是否纳入正文。
5. 在 **写作** 中编辑文章，在 **预览** 中检查格式和来源链接。
6. 点击 **生成草稿**，保存到 `ThoughtSpace/草稿/` 并打开独立 Markdown 文件；之后可用 **打开上次草稿** 返回。

编排中的标题和批注不会改写原材料。修改已生成的独立草稿不会自动反写白板文章；再次生成会创建独立文件。需要按最新编排重建正文时，用 **写作选项 → 从编排重建正文（先另存当前正文）**。

在 **固定参考 → 选段引用** 中，可选已有标题、块、段落，或在只读原文中直接选文字。**引用原文** 插入静态引文与来源行号；**嵌入** 随来源更新，只对已有且唯一的标题或块开放；**仅来源链接** 不复制正文。自由选段的链接指向来源文件，文本卡片的选段按字面文字引用并链接回白板原卡片，避免相对链接被误解释；不自动向来源添加块标识。插入使用打开选段窗口前的正文选区；原文、正文或位置发生变化时拒绝旧操作，请重新选择。

编辑区上方的 **正文目录** 识别 ATX（`#`）和单行 Setext 标题，与“编排”材料顺序分开。展开可跳到章节、查看本节正文的字词数并手动标记完成。重排内容不变的章节会保留标记；改写或改名后回到待完成。重复标题按实际位置分别显示；完全相同章节的数量变化时，相关完成标记保守清除，避免移给错误章节。代码块、属性、引用及列表中的伪标题不会进入目录。多行文字加下划线沿用当前 Obsidian 的普通段落语义。

**编排已变化，正文未同步** 仅提醒，不覆盖你的改写；可继续写作，或明确选择 **备份并从编排重建**。对照记录在首次组装正文及安全重建时建立；仅在文末追加新材料、原对照没有待处理变化且读取期间编排不变时推进对照，不会掩盖之前的编排变化。旧文章若缺少对照，会显示“尚无编排对照”，并保留原正文；重建后开始跟踪。这不是来源笔记自动同步或正文自动合并。

## 13. 视频、音频和时间点摘录

### 选择播放位置

点击 Obsidian 左侧 **ThoughtSpace 音视频笔记**，选择媒体。无需先打开白板。命令面板提供 **在主页面打开媒体播放器、在右侧栏打开媒体播放器、在独立窗口打开媒体播放器**；音视频文件右键也有播放入口。

播放器右上角 **更多媒体操作** 可换媒体、切换这三个位置或 **将媒体加入白板**。同一媒体迁移时延续播放状态；未保存摘录会阻止切换，先保存或清空草稿。

宽窗口左侧观看，右侧是 **当前草稿** 与时间轴。顶部 **布局** 调整观看区宽度，**恢复均衡布局** 恢复比例。窄侧栏用 **写摘录 / 时间轴** 切换；较矮但足够宽的窗口保留分区并使用局部滚动。保存和翻页操作保持可见。

**专注播放** 隐藏记录区；**收起画面** 保留播放控制并让出空间。工作区切换到其他标签页后可以继续播放，关闭播放器窗口会释放播放资源。

### 仓库内媒体与仓库外本地媒体

仓库内文件可以直接选择，或通过 **插入内容 → 视频卡片 / 音频卡片** 加到白板，也可从文件列表和搜索结果拖入。

对于保存在电脑其他位置的大视频，使用本地引用：

1. 在媒体选择列表或播放器 **更多媒体操作** 中选择 **链接仓库外的视频或音频**；白板媒体插入也提供此入口。
2. 粘贴本机完整文件路径或 `file://` 链接，点击 **链接文件**。
3. 插件检查文件后，在仓库创建 `.tsvideo` / `.tsaudio` 小型引用文件，原媒体留在原位置。
4. 像普通媒体一样播放、跳转、摘录或截图。

外部引用不会把大视频复制到仓库，也不会自动把它同步到其他设备。另一台电脑上的路径必须可用。原文件移动或内容变化后重新链接会生成新引用，旧摘录保留，但不会自动改绑到新来源；不要把引用文件误当成媒体本身的备份。

时间链接通过仓库内的 `.tsvideo` / `.tsaudio` 引用定位原媒体，无需把视频移入仓库。若旧时间链接因仓库名或路径中的空格而提示“媒体链接无效或属于其他仓库”，更新后可在白板预览中直接点击原链接；新生成的链接已修正空格编码。白板外的旧链接仍可能受 Obsidian 原生协议解析影响，需要重新生成时间链接。真正属于其他仓库或已经丢失的来源不会自动改绑。

### 记录一个片段

以下步骤 1–5 用于本地媒体工作区；在线视频的独立工作区按钮见 [在线视频与时间戳回源](#在线视频与时间戳回源)。

**白板里的 B 站 / YouTube 卡片：** 点击卡片底部 **加载视频**，等待实际播放时间同步后，直接使用 **记下此刻** 或 **截取画面**。摘录会保存到媒体 Markdown 笔记，同时在原视频右侧生成带时间链接和连线的卡片；点击时间链接可回到这块白板的来源视频。顶部 **笔记** 打开完整的在线视频笔记工作区。首次打开白板不会自动加载在线视频。

截取画面不暂停视频；保存失败时使用 **重试保存** 重试同一份截图和时间戳。重试完成前保持该卡片展开并留在可见区域，关闭或卸载卡片不会持久保存尚未写入的临时截图。分 P 或视频来源变化时停止摘录，重新加载原视频后继续；平台限制读取画面时会显示原因。

1. 播放到需要的位置，点击 **记下此刻**，固定摘录时间。
2. 在 **当前草稿** 输入 Markdown，例如“此处说明城市降温观测的方法与限制”。直接开始输入也会固定当时的播放时间。
3. 视频需要画面时，点击 **截取画面**；截图加入当前草稿，可点击预览放大。
4. 点击 **保存摘录** 或按 `Ctrl/Cmd + Enter`，写入普通 Markdown 笔记。
5. 在时间轴点击时间回看；使用条目的发送按钮将已保存摘录作为原笔记块引用加入白板。引用包含截图和时间，原笔记更新后刷新；重复添加复用节点，没有稳定锚点的旧摘录需先打开原笔记处理。

打开播放器本身不会创建摘录笔记。本地媒体工作区的未保存文字、PNG 截图、来源和时间点会独立暂存到本机；重载插件或重启 Obsidian 后，通过通知、来源顶栏“恢复 / 丢弃”或恢复命令审核。恢复不会写正式笔记，仍需点击“保存摘录”。来源变化时保留只读草稿，缺失来源可复制文字或导出截图。暂存不跨设备同步，清理配置或移动库不自动迁移；突然终止可能损失最后 350 ms 输入或未完成写入。此功能不涵盖在线视频草稿。

### 时间轴与播放工具

时间轴搜索覆盖已读取的全部摘录，可用 **全部 / 文字 / 截图** 筛选，展开长正文，切换舒展或紧凑显示，定位当前时间或最后一条。每页最多显示 50 条，用底部按钮翻页。

播放器提供倍速、前后 10 秒、精确跳转和 A–B 循环；高级播放选项在播放区域的更多菜单中。原生全屏和画中画取决于宿主支持。仓库内媒体同目录、同名的 `.vtt` / `.srt` 可作字幕。外部媒体按仓库中引用文件的目录和基础文件名寻找字幕，不会自动读取外部视频旁的字幕；不提供自动转录。

最近 80 份媒体的时间、倍速、音量和循环状态保存在插件目录的 `media-playback.json`。同时只让一个内置媒体实例播放；换媒体不会自动播放。

白板媒体卡片支持调整大小、折叠、连线和摘录，可转到侧栏记录。白板卡片离屏或折叠时释放播放器资源，持续观看建议使用独立媒体工作区。

支持常见视频和音频扩展名，包括 MP4、WebM、MOV、M4V、OGV、MP3、M4A、WAV、OGG、OGA、FLAC、AAC、OPUS；能否解码由 Obsidian 内置浏览器决定。从电脑拖入并复制媒体仍有 **128 MB** 上限，大文件可用外部本地引用。

### 在线视频与时间戳回源

1. 在音视频选择器选择 **B 站 / YouTube 在线视频**，粘贴你要研究的真实来源链接；也可粘贴到白板，点击 **播放**。
2. 独立在线视频工作区在 **记录摘录** 区域点 **记下此刻** 固定时间、**快速截图** 截取当前帧，再点 **保存摘录**。平台未同步时，可显式使用 **手动时间（备用）**。
3. 白板内在线视频卡片先点 **加载视频**，时间同步后用 **记下此刻 / 截取画面**；摘录保存到 Markdown 笔记，并在来源右侧生成卡片与连线。
4. 点击已保存摘录的时间戳回看。优先复用当前白板的匹配来源播放器；旧链接也可复用已打开的来源白板。多个同源播放器无法确定时，回退独立媒体工作区，不随意任选，也不自动新增播放器。

本地媒体定位后可能提示点击播放；跳转不承诺自动播放。旧影笺笔记精确指向本库媒体时，时间点也可在内置播放器回看。在线视频直接使用隔离播放器，播放、登录、地区与截图权限仍受平台限制；切换视频或分 P 时确认新来源，旧笔记保留。画面未就绪、来源变化或无法读取画面时，检查具体提示并保留草稿，不把失败截图当已保存。

## 14. 日历与日记是可选独立插件

白板中的 **工作区 → 日历与日记**，以及打开日历、今日日记等命令，需要另行安装并启用 **ThoughtSpace 日历与日记**（插件 ID：`thoughtspace-calendar`）。

没有安装时会显示启用提示，不影响白板、笔记、写作和媒体功能。日记目录、任务和日历外观在独立日历插件设置中管理；本教程不把独立插件的功能视作白板内置功能。

## 15. 保存、撤销、备份与导出

### 分别检查三类保存

| 内容 | 何时算完成 |
| --- | --- |
| 白板布局、关系和脑图状态 | 普通白板显示 **已保存**；脑图待保存、保护或错误提示处理完后，再离开当前页 |
| 笔记卡片正文 / 原生 Properties | 编辑器保存完成；原位编辑点 **保存**，失败保留草稿重试 |
| 媒体摘录 | 点 **保存摘录** 后写入普通 Markdown 笔记；暂存草稿不是正式摘录 |

普通白板在标题栏显示保存状态；脑图在已有状态区域显示待保存、保护和错误，正常完成时该区域可能隐藏。原生页占用时，状态提供 **定位原生页**；旧页已关但还在保存时继续等待。发生布局冲突时，只有实际生成且仍存在的恢复文件才出现 **打开恢复草稿**。这些动作不会自动关页、解除写保护或合并全文。

白板撤销用于布局、对象、连接和相关白板操作。原生笔记编辑使用编辑器自己的撤销；文件归档移动、生成文件和外部媒体文件不属于白板布局撤销。删除白板上的引用通常保留原文件，撤销新建笔记转换也可能保留已生成文件。

### 快照与完整备份

从 **工作区 → 快照与导出** 进入 **视角与快照**，可保存和恢复布局快照、复制整张白板，或导出大纲。

- **常用视角**：位置和缩放。
- **布局快照**：白板内容和结构；不会回滚关联 Markdown 笔记正文。
- **复制整张白板**：创建另一份白板；其中的笔记引用仍可能指向相同原文件。
- **完整仓库备份**：白板、Markdown、附件及配置目录；外部媒体需另行备份。

布局快照位于插件目录的 `layout-snapshots/`，恢复前会自动保存当前布局。按标签归档的备份位于 `filing-backups/`。如果同步工具不包含配置目录，这些备份不会随普通笔记一起同步。

### 选择导出方式

| 目的 | 入口与结果 |
| --- | --- |
| 在 Obsidian 原生 Canvas 中查看 | **工作区 → 导出 Canvas**，创建 `.canvas` 文件 |
| 获取文本结构与关系 | **快照与导出 → 导出 Markdown 大纲** |
| 把笔记关联带入原生链接体系 | **快照与导出 → 导出原生链接索引** |
| 导出导图分支 | **思维导图工作台 → 导出 Markdown / 导出 SVG** |
| 导出资料表 | **卡片资料库 → 导出 CSV** |
| 形成可继续写作的文章 | **白板写作 → 生成草稿** |

导出是当时的结果，不是持续双向同步，也不是完整备份。外部媒体相关导出保留播放器或时间点链接，不会附带媒体文件；ThoughtSpace 专属交互不保证在原生 Canvas 中等同呈现。

## 16. 保存、只读、冲突与恢复 FAQ

| 现象 | 下一步 |
| --- | --- |
| 第三方插件列表中找不到插件 | 检查桌面版 Obsidian、配置目录与同版本三个运行文件，避免多嵌套文件夹；重新加载后启用 |
| 左键、滚轮或快捷键与教程不同 | 查看 **鼠标与键盘** 当前方案；退出文字输入并点击画布，核对 Obsidian 自定义绑定 |
| 四向脑图命令未执行 | 先确认活动页为独立脑图、中心未锁定且非只读，完成组字并退出输入/编辑；命令没有默认热键 |
| 找不到刚才的白板或材料 | 用 **继续上次白板**、空间总览 **最近打开**、适应、搜索或大纲；检查分组、分支折叠与筛选 |
| Markdown 文件列表打开后看见正文和 JSON | 这是原生页；在当前页菜单选 **返回白板**，或命令 **以白板打开当前 Markdown**；不要删除布局区 |
| 原生 Markdown 已打开 · 白板仅查看 | 点 **定位原生页**，保存属性和正文；保存并关闭其他同文件页，再从保留页 **返回白板** |
| 旧原生页保存尚未确认 · 等待保存完成 | 页签关闭不等于保存结束；等待后续保存和新读取完成，不强制解除保护 |
| 返回白板被取消 | 最新输入、页面切换、更名或保存未完成都可取消交接；原生页保留，确认最新内容保存后重试 |
| 布局冲突 / 写入暂停 | 有 **打开恢复草稿** 时先保留该文件；对照原文件与草稿，再处理同步/外部修改。不要继续覆盖原文件 |
| 恢复草稿不可用 / 保存失败 | 保持当前页面打开，复制可见未保存内容并保留已有恢复文件；不要把错误状态当已保存或先关闭全部页 |
| 新建关闭后文件仍存在 | 已开始的文件写入可能完成；从文件列表检查，避免再创建编号副本。偏好保存失败不删除已经创建的文件 |
| 模板创建已停止 | 多文件创建不是原子操作；按提示核对已生成的白板/笔记，不盲目重试整个模板 |
| 强制退出后原生最新输入找不到 | 尚未落盘正文没有跨进程恢复保证。File recovery 可能只有旧保存快照，不等于包含最新输入 |
| 卡片正文在别处也变化 | 多个卡片可能引用同一 Markdown；需要独立正文先复制原笔记 |
| 对象不能移动或整理 | 检查对象、组内或分支中的锁定内容，按预览提示解锁或缩小范围 |
| PDF 无法选中文字 / 首次解析较慢 | 在右侧原生阅读器操作；扫描页需另行 OCR；减少同时可见复杂材料，分组折叠或拆子白板 |
| 音视频不能播放 / 来源已变化 | 检查文件可达性、编码与真实来源；外部路径变更需重新关联，引用文件不是媒体备份 |
| 媒体不能切换 / 保存失败 | 先保存或清空未保存摘录，等待截图/写入结束；失败时保持草稿并用重试 |
| 本地媒体草稿重开后未显示 | 使用来源顶栏 **恢复 / 丢弃** 或 **恢复暂存的媒体摘录** 查看本机暂存；在线草稿不在这一恢复范围 |
| Markdown 编辑回退源码 | 宿主无法使用内嵌实时预览时继续用源码，保存后检查渲染 |
| 原生搜索未找到新白板内容 | 等待索引更新，检查 **白板原生搜索**，必要时运行 **重建白板原生搜索索引** |
| 日历入口提示未启用 | 另行安装并启用 ThoughtSpace 日历与日记；不影响白板主流程 |

冲突恢复草稿按原格式创建于原目录，名称会避开已有文件；既可能是 `.md`，也可能是 `.thoughtspace`。草稿包含本地布局和此前验证过的文档，不保证已经合并外部最新属性或正文。布局快照不回滚所有原笔记文件，需结合完整仓库备份核查。通用导出入口也不保证包含保存失败时未落盘的本地布局，不能仅因生成导出文件就清除当前会话。

原生多个编辑器持有不同全文时，后续宿主保存仍可能覆盖较早草稿或外部修改。布局保护不等于自动合并全文，也不提供任意原生未保存输入的强制退出恢复。详细说明见 [Markdown 白板的保存与恢复边界](markdown-boards.zh-CN.md#同文件的多个视图与同步修改)。
