# 资料卡插入正文与 PDF 摘录

## 把资料卡放进文章

在资料库鸟瞰卡片的拖动按钮，或写作材料列表中，拖动 Markdown 资料卡到正文中的位置。松手后选择：

- **链接**：插入原生 Obsidian 链接，点击打开来源。
- **嵌入**：插入原生嵌入，显示内容随来源变化。
- **正文**：复制当前正文，之后分别编辑。
- **标题＋正文**：复制标题和当前正文，之后分别编辑。

“范围”可以选择整篇或具有可靠原生标题索引的章节。章节包含其下级标题，到下一个同级或上级标题前结束；重复或无法确认的标题不提供猜测锚点。复制正文时不带 YAML 属性，也不向来源写入块 ID。正文内的本地引用会按目标上下文重新定位。

选择操作前不会写入目标。Esc、取消或切换页面会结束本次操作；来源或目标变化后须重新拖动。插入是一次可撤销操作。支持原生 Markdown 源码/实时预览和白板写作正文；源码退路若无法提供可撤销插入会明确拒绝。

## PDF 摘录与分支

在原生 PDF 视图选择文字，在浮动工具中选择摘录颜色，然后加入白板或拖到主题上。主题中部作为子主题，靠上/靠下区域作为前一个/后一个同级主题，松手前显示落点。已有 PDF 摘录也可以拖动重组，结构和位置一同撤销；取消不改变分支。

颜色和来源信息保存在插件白板数据中，**不改写 PDF 文件**。摘录保留文件身份、页码、原文；单页原生文字层可用时还保留文字指纹及选区位置。

使用“回到 PDF 选区”或摘录来源入口时，只有文件身份及原页文字一致才显示精确高亮。文件更新、跨页摘录、无原生文字层或锚点失效时，退回请求页码并显示提示，原摘录保留。不会用相似文本猜测位置，也不执行 OCR。改变缩放或旋转后，高亮按当前文字层重新计算。
