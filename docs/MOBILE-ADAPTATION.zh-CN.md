# 手机、平板与分屏 · 1.3.36-beta.2 预发布

本候选在既有“新建 → 手写白板”基础上适配普通白板、脑图、手写、搜索、材料、媒体、在线记录、写作及设置。容器宽度决定布局，visualViewport 与安全区域约束可见高度；布局变化不重建正在编辑的正文或播放器。桌面鼠标、键盘和原生保存所有权继续使用原有保护。

## 操作

- 普通卡片正文用手指滚动阅读，拖动标题移动卡片，拖动尺寸手柄调整大小；明确点击编辑入口进入正文编辑。
- 脑图空白画布用双指移动、缩放；节点标题、编辑按钮与正文保留自己的操作归属。缩放与分页在画布外的控制栏，窄容器或触摸环境增大节点按钮命中区域。短窗控制区可纵向滚动，保留画布的操作空间。显示、保存与重开统一使用 15%–250% 缩放范围；“适应画布”达到 15% 下限后，可继续平移阅读超出短窗的内容。
- 手写默认单指不落墨；笔或鼠标可书写，双指导航。需要单指画画时显式打开“手指书写”，重开视图默认关闭。旋转、分屏和视口变化保留未抬笔草稿与镜头；取消、失焦、离开页面与原生写保护仍取消未提交输入。
- 搜索的筛选可收起；材料列表与详情通过页签切换，保留各自输入和滚动位置。设置与新建弹窗在短窗中可滚动，取消和连续点击不产生额外文件。资料库顶部操作按弹窗自身宽度换行，计数保持横排，表格保留内部横向滚动。
- 窄媒体/在线工作区在播放器、记录、时间线间切换，保留输入与播放器。媒体“专注播放”立即进入播放页，退出或选择摘录/时间线时恢复记录操作；恢复旧状态或桌面收窄也保持一致。写作引用栏按需打开，可点外部或 Escape 收起；正文编辑器在高度变化、页签切换和同页状态刷新时保留。窄容器或触摸环境中的媒体、在线记录与写作操作按钮至少 44px 高，短窗可滚动到保存与生成入口。
- 内嵌实时预览不可用时，写作使用 Markdown 源码文本框；它保留至少 100px 高度，说明、工具栏和正文所在区域可纵向滚动，短窗输入与草稿继续保留。
- 移动在线记录使用手动时间输入，可由用户点击在浏览器打开原链接。移动端不启动 Electron 播放器、电脑外部路径或桌面后端；“新窗口”退回当前应用页签。

## 保存与恢复

原生 Markdown/Properties 正在编辑或其他窗口仍拥有保存时，白板保持写保护；取消交接、更新导航和未知保存能力不会解除保护。文档冲突不覆盖原文件。失败时查看具体提示，重试或打开恢复副本；确认保存完成后再重开。

写作在原文件保存和备用草稿保存同时失败时，会保留当前会话中的独立文本副本，提供只读文本复制与重试入口。白板、脑图与手写的“复制未保存白板”入口显示当前完整只读副本，包含笔迹、视角及原生属性/正文；复制到独立文件时保持原格式。打开、取消或复制都不写原文件，也不解除保护。剪贴板被拒绝时内容仍可选择复制。**内存副本不能承受完整应用关闭、强制退出或设备掉电；关闭前先复制到可靠位置，或完成成功保存。**完整重开验收使用已经持久化的保存检查点，不能解释为全存储故障下的跨进程恢复。

手写使用扩展 v3 数据。1.3.35 及更早版本不能打开新手写类型，退回旧版本前保留完整副本，不用旧版覆盖它。原生 Canvas 导出会拒绝丢失笔迹的转换。

## 验证范围

首轮使用 Mac Studio 的隔离 Obsidian 1.14.4 实例、专用测试仓库/配置与独立 CDP 端口，模拟 360/390/430 手机、768/820/1024 平板的横竖屏、分屏及键盘可见区域变化。触摸使用 Chromium CDP 输入，笔使用明确标注的合成 PointerEvents；移动启动检查禁止候选加载 Node/Electron。[beta.2 验证说明](../qa/RELEASE-1.3.36-beta.2.md) 区分首轮尺寸矩阵与当前第二轮构建，记录持续输入、100/1000 节点对照、故障恢复及缩放一致性修复。

真实 iOS/Android、WKWebView、系统软键盘/IME、Pencil 硬件压力/延迟和掌拒仍未验证；没有通用掌拒、Pencil 双击、悬停、PencilKit 或 OCR 保证。桌面模拟性能不代表手机性能。请在独立测试仓库中先试用，保留原文件副本。
